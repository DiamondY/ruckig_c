# ruckig_c 0.5.0

`0.5.0` is the stable tracking Fast-mode release. It stabilizes the public C
tracking ABI introduced on the `0.5.0-design` line and ships local online and
offline Fast tracking. `RUCKIG_TRACKING_OPTIMIZED` remains declared for API
shape parity but returns `RUCKIG_ERROR_UNSUPPORTED` throughout `0.5.x`; the
bounded local `Optimized` implementation is deferred to `0.6.0-design`.

## Highlights

- Stabilized the public C tracking ABI:
  - `ruckig_tracking_t`
  - `ruckig_target_state_t`
  - `ruckig_target_state_sequence_t`
  - `ruckig_tracking_output_sequence_t`
  - online `ruckig_tracking_update`
  - offline `ruckig_tracking_calculate_sequence`
- Included local Fast-mode tracking using deterministic constant-acceleration
  lookahead.
- Included offline tracking output sequences for position, velocity,
  acceleration, jerk, time, section, and per-step result code.
- Kept `Optimized` tracking unsupported in `0.5.x`; it is not aliased to Fast.
- Promoted ABI artifact paths to `artifacts/abi/0.5.0`.
- Retained no-waypoint solver and waypoint optimizer regression gates from the
  prior stable releases.
- Kept Python `cffi` and Rust wrapper work as prototype/alpha evidence only.

## Compatibility

- Public C ABI additions since `v0.4.2`: 47 approved tracking symbols.
- Public C symbol allowlist: 164 symbols.
- Existing `v0.4.2` public functions, signatures, enum numeric values, and
  result-code numeric values are unchanged.
- `RUCKIG_TRACKING_FAST = 0`.
- `RUCKIG_TRACKING_OPTIMIZED = 1`.
- `Optimized` online/offline calls return `RUCKIG_ERROR_UNSUPPORTED`.
- `interrupt_calculation_duration` does not create tracking timeout,
  soft-interruption, or hard real-time guarantees.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.

## Remote Publication Contingency

Remote release publication requires working GitHub authentication and network
access. If `gh auth` or GitHub connectivity is unavailable, the release should
stop at the release-candidate evidence commit and these notes should be used as
the manual publication checklist. Do not invent CI run ids or manual workflow
evidence.

## Deferred

- Bounded local `Optimized` tracking implementation is deferred to
  `0.6.0-design`.
- Soft interruption checkpoints are deferred.
- Cloud and remote calculation are not implemented.
- No formal Ruckig Pro/cloud numerical equivalence claim is made.
- No hard or soft real-time tracking guarantee is made.
- Python wheels are not published.
- Rust crate publication is deferred.
- Package-manager recipes are deferred.
- Upstream baseline upgrade is deferred.
