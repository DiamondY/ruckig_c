# ruckig_c 0.10.0

`0.10.0` is the stable Visualization v2 evidence release. It keeps the
`v0.9.0` 172-symbol public C ABI unchanged while stabilizing the local
30-PNG Visualization v2 gallery, local verifier, strict regeneration evidence,
and manual-only CI artifact workflow reviewed during `0.10.0-readiness`.

## Highlights

- Stabilized the committed Visualization v2 gallery as 30 project-owned
  `1400x900` PNG files under `docs/assets/visualization/`.
- Stabilized `tools/visualization/generate_gallery.py` and
  `tools/visualization/verify_gallery.py` as local documentation/evidence
  tooling.
- Stabilized strict regeneration evidence for the committed gallery and
  manifest.
- Stabilized the optional manual `visualization_artifacts=true` workflow as a
  review artifact path, while keeping it off ordinary push and pull-request CI.
- Kept the existing manifest label,
  `0.10.0-alpha visualization v2 evidence`, intentionally as asset provenance.
- Kept the previous v1 gallery provenance available through the `v0.9.0` tag
  rather than duplicating old assets on `main`.

## Compatibility

- Public C ABI: unchanged from `v0.9.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.10.0`: 0.
- Public removals in `v0.10.0`: 0.
- Unapproved exported symbols: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- Visualization v2 does not add visualization-specific public C functions,
  exported symbols, public diagnostics fields, or stable package APIs.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
