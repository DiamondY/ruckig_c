# ruckig_c 0.6.0

`0.6.0` is the stable bounded local `Optimized` tracking release. It
stabilizes the public C Optimized tracking API introduced during
`0.6.0-design` and keeps the existing local Fast-mode online/offline tracking
behavior from `v0.5.0`.

## Highlights

- Stabilized bounded local `RUCKIG_TRACKING_OPTIMIZED` behavior.
- Added online Optimized lookahead through
  `ruckig_tracking_update_with_lookahead`.
- Added candidate-budget and diagnostic APIs for Optimized tracking.
- Included offline Optimized sliding-window sequence calculation.
- Kept Fast fallback as the valid success fallback when Optimized candidates do
  not improve the Fast baseline; callers can inspect fallback through
  `ruckig_tracking_get_last_calculation_status`.
- Retained no-waypoint solver and waypoint optimizer regression gates from the
  prior stable releases.
- Kept Python `cffi` and Rust wrapper work as prototype/alpha evidence only.

## Compatibility

- Public C ABI additions since `v0.5.0`: 5 approved Optimized tracking
  symbols.
- Public C symbol allowlist: 169 symbols.
- Existing `v0.5.0` public functions, signatures, enum numeric values, and
  result-code numeric values are unchanged.
- `RUCKIG_TRACKING_FAST = 0`.
- `RUCKIG_TRACKING_OPTIMIZED = 1`.
- `RUCKIG_TRACKING_OPTIMIZED` is a bounded deterministic local MVP, not a
  formal global optimizer.
- `interrupt_calculation_duration` does not create tracking timeout,
  soft-interruption, or hard real-time guarantees.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
