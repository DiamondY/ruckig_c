# ruckig_c 0.9.0

`0.9.0` is the stable tracking quality and stability evidence release. It keeps
the `v0.8.0` 172-symbol public C ABI unchanged while stabilizing the tracking
random audit, tuned evaluator hardening, and fixed stability regression evidence
reviewed during `0.9.0-readiness`.

## Highlights

- Stabilized deterministic Optimized tracking audit evidence through
  `ruckig_c_tests --tracking-random-audit`.
- Stabilized tuned bounded-local Optimized tracking evaluator quality evidence
  with hard 10k, 100k, and 1M per-strategy thresholds.
- Stabilized fixed tracking stability regression evidence through
  `ruckig_c_tests --tracking-stability`.
- Kept `--tracking-random` behavior and output unchanged.
- Kept tracking attribution private to test-runner evidence; no public
  diagnostics fields, public functions, or exported symbols are added.

## Compatibility

- Public C ABI: unchanged from `v0.8.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.9.0`: 0.
- Public removals in `v0.9.0`: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- `RUCKIG_TRACKING_OPTIMIZED` remains a bounded deterministic local evaluator,
  not a formal global optimizer.
- No Pro/cloud equivalence claim is made.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.

## Evidence Summary

Final local and remote release evidence is recorded in
`docs/release/checklists/0.9.0.md`.

- Static and shared Windows clang/Ninja CTest gates pass.
- Tracking focused CTest gates pass, including random audit, quality hardening,
  and stability regression selectors.
- Fixed no-waypoint oracle comparison count: 82.
- Waypoint section-oracle comparison count: 4.
- Ordinary random oracle: `100000` cases each for seeds `1`, `2`, and `41`.
- Per-DoF random oracle: `100000` cases for seed `1`.
- Local release-random CTest and local `1000000 --seed 1` oracle executable
  pass.
- Tracking audit hard gates pass for 10k seed `1`, 100k seeds `1`, `2`, `41`,
  and 1M seed `1`.
- Performance and coverage are recorded as local release evidence.
- Public symbol allowlist verification and exported-symbol comparison are
  clean.
- Python prototype smoke and Rust alpha wrapper smoke pass.
- Release-candidate commit, final evidence commit, annotated tag, tag CI,
  manual release-random workflows, and GitHub Release publication are recorded
  in the release checklist.
