# ruckig_c 0.4.2

`0.4.2` is an original parity coverage and evidence closeout release for the
`0.4.x` original-surface parity line. It keeps the `v0.4.0` public C ABI
unchanged while recording the current coverage estimate, required tracking gap,
and future soft-interruption design boundary before `0.5.0-design`.

## Highlights

- Added `docs/current/original_parity_coverage.md`, a layered coverage matrix
  against the frozen original reference and broader original product surface.
- Recorded tracking as a mandatory full-original-parity gap for `0.5.0-design`.
- Added tracking interface design preparation without adding public tracking
  API or implementation in `0.4.2`.
- Added interrupt calculation duration design notes clarifying that `0.4.x`
  stores the value but does not implement optimizer interruption checkpoints.
- Updated ABI artifact paths to `artifacts/abi/0.4.2`.

## Compatibility

- Public C ABI additions: 0.
- Public C symbol allowlist: 117 symbols, unchanged from `v0.4.0` and
  `v0.4.1`.
- Existing public functions, signatures, enum numeric values, and result-code
  numeric values are unchanged.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
- Tracking is design-only in this release.
- `interrupt_calculation_duration` remains storage/API-surface parity. This
  release does not implement optimizer interruption checkpoints and does not
  claim hard or soft real-time waypoint optimization.

## Coverage Summary

- Community no-waypoint target solver behavior: estimated `93-96%`.
- C runtime / motion API replacement surface: estimated `82-87%`.
- Waypoint and per-section behavior versus full Pro/cloud behavior: estimated
  `60-70%`.
- Waypoint and per-section behavior versus declared local optimizer scope:
  estimated `75-80%`.
- Bindings and ecosystem: estimated `35-45%`.
- Full original repository/product parity: estimated `70-75%`.

These estimates are engineering estimates for release planning, not line
coverage, branch coverage, or formal numerical-equivalence proof.

## Deferred

- Tracking public C API and implementation are deferred to `0.5.0-design`.
- Soft interruption checkpoints for waypoint optimization are deferred.
- Cloud and remote calculation are not implemented.
- No formal Ruckig Pro/cloud global numerical equivalence claim is made.
- No hard real-time guarantee is made for waypoint optimization.
- Python wheels are not published.
- Rust crate publication is deferred.
- Package-manager recipes are deferred.
- New public C API expansion outside `0.5.0-design` is deferred to a separate
  version decision.
- Upstream baseline upgrade is deferred; `original/ruckig-main` remains frozen
  as Ruckig Community `0.17.3`.
