# ruckig_c 0.11.0

`0.11.0` is the stable waypoint soft-interruption and platform-clock evidence
release. It keeps the `v0.9.0` 172-symbol public C ABI unchanged while
stabilizing waypoint `ruckig_update` soft-interruption V1 and the internal
platform clock abstraction reviewed during `0.11.0-readiness`.

## Highlights

- Stabilized soft interruption for new waypoint `ruckig_update` trajectory
  calculations using the existing `interrupt_calculation_duration` input field.
- Stabilized `ruckig_output_was_calculation_interrupted` as the status for
  waypoint `ruckig_update` soft-interruption results.
- Preserved existing behavior for public `ruckig_calculate`, no-waypoint
  target solving, and tracking when the interrupt field is set.
- Stabilized an internal monotonic platform clock abstraction with Windows and
  POSIX defaults plus compile-time custom provider hooks for embedded, RTOS, or
  bare-metal ports.
- Kept soft interruption as a soft budget checked only at complete waypoint
  candidate boundaries; no hard real-time guarantee is claimed.
- Kept Cloud/remote runtime and proprietary Pro numerical equivalence out of
  scope.

## Compatibility

- Public C ABI: unchanged from `v0.10.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.11.0`: 0.
- Public removals in `v0.11.0`: 0.
- Unapproved exported symbols: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- The platform clock abstraction is internal and compile-time only; it does not
  add a runtime setter, exported symbol, public struct field, or public C ABI
  hook.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
