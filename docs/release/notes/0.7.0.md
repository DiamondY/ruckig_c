# ruckig_c 0.7.0

`0.7.0` is the stable Optimized tracking strategy and diagnostics release. It
stabilizes the 172-symbol public C ABI reviewed during `0.7.0-readiness`: the
bounded local Optimized tracking API from `v0.6.0`, high-level strategy preset
controls, and the public tracking diagnostics snapshot.

## Highlights

- Stabilized `Stable`, `Balanced`, and `Aggressive` Optimized tracking
  strategy presets.
- Stabilized `ruckig_tracking_set_optimized_strategy` and
  `ruckig_tracking_get_optimized_strategy`.
- Stabilized `ruckig_tracking_diagnostics_t` and
  `ruckig_tracking_get_last_diagnostics`.
- Kept bounded deterministic local Optimized tracking with Fast fallback and
  observable diagnostics.
- Retained no-waypoint solver, waypoint optimizer, tracking quality, ABI/export
  and wrapper smoke gates from the `0.7.0-readiness` evidence line.
- Kept Python `cffi` and Rust wrapper work as prototype/alpha evidence only.

## Compatibility

- Public C ABI additions since `v0.6.0`: 3 approved strategy/diagnostics
  symbols.
- Public C symbol allowlist: 172 symbols.
- Existing `v0.6.0` public functions, signatures, enum numeric values, and
  result-code numeric values are unchanged.
- `RUCKIG_TRACKING_OPTIMIZED_STABLE = 0`.
- `RUCKIG_TRACKING_OPTIMIZED_BALANCED = 1`.
- `RUCKIG_TRACKING_OPTIMIZED_AGGRESSIVE = 2`.
- `RUCKIG_TRACKING_OPTIMIZED` is a bounded deterministic local evaluator, not
  a formal global optimizer.
- Fast fallback is observable through tracking diagnostics.
- `interrupt_calculation_duration` does not create tracking timeout,
  soft-interruption, or hard real-time guarantees.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
