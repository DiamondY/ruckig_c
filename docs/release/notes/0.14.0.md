# ruckig_c 0.14.0

`0.14.0` is the stable API-neutral interrupt surface release. It keeps the
`v0.13.0` 172-symbol public C ABI unchanged while stabilizing the
`0.14.0-alpha.1` through `0.14.0-alpha.5` waypoint, no-waypoint, and online
tracking interruption evidence reviewed during `0.14.0-readiness`.

## Highlights

- Stabilized the post-`v0.13.0` interrupt boundary audit proving public
  `ruckig_calculate` remains complete and non-interruptible.
- Stabilized waypoint `ruckig_update` true-resume behavior from the existing
  private waypoint engine line.
- Added no-waypoint `ruckig_update` complete-trajectory-boundary interruption
  through the existing interrupt field and output flag, without true-resume or
  a public API addition.
- Added Optimized online tracking candidate-boundary interruption for
  `ruckig_tracking_update` and `ruckig_tracking_update_with_lookahead`,
  publishing the best complete candidate evaluated so far when the budget
  expires.
- Kept `ruckig_tracking_calculate_sequence` deferred because the public
  sequence output has no API-neutral interruption carrier.
- Preserved allocation-free online paths after object/input/output
  construction.

## Compatibility

- Public C ABI: unchanged from `v0.13.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.14.0`: 0.
- Public removals in `v0.14.0`: 0.
- Unapproved exported symbols: 0.
- Existing public function signatures, public structs, enum numeric values,
  and result-code numeric values are unchanged.
- The only public header change is the version macros/string moving to
  `0.14.0`.
- `RUCKIG_C_ENABLE_CALCULATION_DURATION` still controls only public
  calculation-duration reporting, not interruption availability.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
