# ruckig_c 0.12.0

`0.12.0` is the stable waypoint soft-interruption true-resume release. It
keeps the `v0.9.0` 172-symbol public C ABI unchanged while stabilizing the
`0.12.0-alpha.1` and `0.12.0-alpha.2` waypoint `ruckig_update`
soft-interruption work reviewed during `0.12.0-readiness`.

## Highlights

- Stabilized private true-resume for waypoint `ruckig_update`
  soft-interruption after the first interrupted trajectory calculation.
- Continued waypoint optimizer work on later normal `pass_to_input` online
  cycles while the interrupt field remains enabled.
- Published background waypoint trajectories only at complete feasible
  candidate boundaries and only when they improve over the incumbent remaining
  trajectory.
- Unified complete waypoint solves and soft-interruption resume on the same
  private step-driven waypoint optimizer engine.
- Preserved complete, non-interruptible behavior for public
  `ruckig_calculate`, no-waypoint target solving, and tracking when
  `interrupt_calculation_duration` is set.
- Kept soft interruption as a soft budget checked at complete waypoint
  candidate boundaries; no hard real-time guarantee or proprietary Pro/cloud
  numerical equivalence claim is made.

## Compatibility

- Public C ABI: unchanged from `v0.11.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.12.0`: 0.
- Public removals in `v0.12.0`: 0.
- Unapproved exported symbols: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- The platform clock abstraction remains internal and compile-time only; no
  runtime clock setter, exported symbol, public struct field, or public C ABI
  hook is added.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
