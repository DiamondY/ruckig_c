# ruckig_c 0.2.0

`ruckig_c 0.2.0` is a pure C99 local trajectory generation library based on the
frozen Ruckig Community `0.17.3` behavior. The C library does not link to or
require the C++ runtime; the original C++ source under `original/ruckig-main` is
used only as a differential test oracle.

## Added

- Per-DoF control-interface overrides through
  `ruckig_input_set_per_dof_control_interface` and
  `ruckig_input_clear_per_dof_control_interface`.
- Per-DoF synchronization overrides through
  `ruckig_input_set_per_dof_synchronization` and
  `ruckig_input_clear_per_dof_synchronization`.
- Fixed C++ oracle cases for mixed position/velocity control overrides and
  mixed `Time`/`None` synchronization overrides.
- C API tests for invalid per-DoF setter inputs, clear behavior, update
  recalculation, and the no-allocation runtime contract with per-DoF settings
  enabled.
- Minimal per-DoF override C example wired into CMake and CTest.

## API Behavior

- Per-DoF setter `count` must equal the input DoF count.
- `NULL` input handles, `NULL` value pointers, count mismatches, and invalid
  enum values return `RUCKIG_ERROR_INVALID_INPUT`.
- Clearing a per-DoF vector restores the matching global setter behavior.
- Per-DoF storage is allocated when the input handle is created.
- `ruckig_calculate`, `ruckig_update`, trajectory sampling, and root solvers
  retain the no-allocation release contract.

## Verification

The `0.2.0` release gate includes:

- Windows clang/Ninja static release CTest.
- Windows clang/Ninja shared-library release CTest.
- Fixed C++ oracle suite.
- Development random oracle runs with `--random 100000 --seed 2` and
  `--random 100000 --seed 41`.
- Release random oracle with `--random 1000000 --seed 1`.
- Linux Clang ASan+UBSan.
- Linux Valgrind.
- Linux Clang performance benchmark.
- Installed CMake consumer and Linux pkg-config consumer smoke tests.

Final commit, CI run ids, and benchmark details are recorded in
`docs/release/checklists/0.2.0.md`, `docs/release/evidence/verification_report.md`, and
`docs/release/evidence/performance_report.md`.

## Deferred

The following features remain outside the public C API:

- Intermediate waypoints.
- Per-section constraints.
- Cloud calculation.
- Python bindings.
- Rust bindings.
- Upstream Ruckig baseline upgrades.

Any future upstream baseline upgrade must be a separate project with source
inventory review, tolerance review, oracle corpus updates, full random stress,
and new performance baselines.
