# ruckig_c 0.13.0

`0.13.0` is the stable waypoint true-resume stress and private engine rewrite
release. It keeps the `v0.12.0` 172-symbol public C ABI unchanged while
stabilizing the `0.13.0-alpha.1` and `0.13.0-alpha.2` waypoint
`ruckig_update` soft-interruption hardening reviewed during
`0.13.0-readiness`.

## Highlights

- Stabilized post-`v0.12.0` stress evidence for waypoint `ruckig_update`
  soft-interruption true-resume.
- Added focused coverage for multi-DoF, multi-waypoint, per-section,
  budget-matrix, fresh full-solve reference, long online-loop, and
  allocation-guarded true-resume behavior.
- Reworked the private waypoint optimizer/resume state into a single internal
  waypoint engine without changing the public C ABI.
- Preserved transaction-style background publishing: resumed optimization only
  replaces the incumbent trajectory with a complete valid improvement.
- Added a deterministic 128-case complete-solve quality baseline to prevent
  regressions against the previous `9d322ad` private engine behavior.
- Preserved complete, non-interruptible behavior for public
  `ruckig_calculate`, no-waypoint target solving, and tracking when
  `interrupt_calculation_duration` is set.

## Compatibility

- Public C ABI: unchanged from `v0.12.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.13.0`: 0.
- Public removals in `v0.13.0`: 0.
- Unapproved exported symbols: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- The platform clock abstraction remains internal and compile-time only; no
  runtime clock setter, exported symbol, public struct field, or public C ABI
  hook is added.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
