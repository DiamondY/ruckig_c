# ruckig_c 0.4.1

`0.4.1` is a deep stabilization release for the `0.4.x` original-surface
parity line. It keeps the `v0.4.0` public C ABI unchanged while strengthening
local waypoint optimizer evidence, waypoint performance trend coverage, and
prototype wrapper smoke.

## Highlights

- Added deeper waypoint optimizer regression coverage for 1D, 2D, 4D, and 8D
  multi-waypoint cases.
- Added coverage for tight global/per-section position bounds, mixed
  per-section velocity/acceleration/jerk constraints, per-section minimum
  duration, disabled DoFs, and nonzero boundary derivatives.
- Strengthened waypoint trajectory invariant checks for intermediate-duration
  ordering, section sampling, per-section sampled limits, position extrema, and
  first-time-at-position across sections.
- Expanded the local C-only waypoint benchmark corpus from 5 to 10 deterministic
  case families, now covering up to 8 DoF and 3 intermediate waypoints.
- Strengthened the experimental Python `cffi` prototype smoke tests with a
  four-DoF mixed per-section waypoint scenario.

## Compatibility

- Public C ABI additions: 0.
- Public C symbol allowlist: 117 symbols, unchanged from `v0.4.0`.
- Existing public functions, signatures, enum numeric values, and result-code
  numeric values are unchanged.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
- `interrupt_calculation_duration` remains storage/API-surface parity. This
  release does not implement optimizer interruption checkpoints and does not
  claim hard or soft real-time waypoint optimization.

## Deferred

- Cloud and remote calculation are not implemented.
- No formal Ruckig Pro/cloud global numerical equivalence claim is made.
- No hard real-time guarantee is made for waypoint optimization.
- Soft interruption checkpoints for waypoint optimization are deferred.
- Python wheels are not published.
- Rust crate publication is deferred.
- Package-manager recipes are deferred.
- New public C API expansion is deferred to a separate design decision.
- Upstream baseline upgrade is deferred; `original/ruckig-main` remains frozen
  as Ruckig Community `0.17.3`.
