# ruckig_c 0.8.0

`0.8.0` is the stable visualization/gallery evidence release. It keeps the
`v0.7.0` 172-symbol public C ABI unchanged while stabilizing the local
Matplotlib PNG gallery and verifier evidence reviewed during
`0.8.0-readiness`.

## Highlights

- Stabilized the project-owned local algorithm visualization gallery under
  `docs/assets/visualization/`.
- Adopted the existing 13 Matplotlib PNG assets and `manifest.json` without
  relabeling or regenerating tracked gallery files during closeout.
- Kept the gallery generated from public C ABI data through the Python `cffi`
  prototype, NumPy, and Matplotlib `Agg`.
- Stabilized the local gallery verifier, including default committed-asset
  checks and optional strict regeneration.
- Kept visualization local-only: no default GitHub Actions plotting job, no
  CMake/CTest gate, no copied original image/PDF assets, and no network,
  cloud, Pro license, or Pro/cloud equivalence claim.

## Compatibility

- Public C ABI: unchanged from `v0.7.0`.
- Public C symbol allowlist: 172 symbols.
- Public additions in `v0.8.0`: 0.
- Public removals in `v0.8.0`: 0.
- Existing public function signatures, enum numeric values, and result-code
  numeric values are unchanged.
- `RUCKIG_TRACKING_OPTIMIZED` remains a bounded deterministic local evaluator,
  not a formal global optimizer.
- Fast fallback remains observable through tracking diagnostics.
- `interrupt_calculation_duration` does not create tracking timeout,
  soft-interruption, or hard real-time guarantees.
- Python `cffi` and Rust wrapper work remain prototype/alpha evidence only; no
  wheel or crate is published.
- `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
