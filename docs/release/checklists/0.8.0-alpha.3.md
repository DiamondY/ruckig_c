# 0.8.0-alpha.3 Visualization Verifier Evidence Checklist

This checklist records the `0.8.0-alpha.3` visualization verification
hardening slice on `0.8.0-design - Unreleased`. It is not a stable release
closeout, does not create a tag or GitHub Release, and does not add public C
API.

## Scope

- [x] Add a local verifier for the committed Matplotlib PNG gallery.
- [x] Keep the alpha.2 PNG files and `manifest.json` unchanged.
- [x] Keep the verifier local-only and outside default GitHub Actions, CMake,
  and CTest gates.
- [x] Verify canonical inventory, PNG dimensions, manifest byte counts and
  SHA-256 hashes, original example mapping, `11-13` exclusions, boundary flags,
  and reproducibility fields.
- [x] Add optional strict regeneration into ignored `out/` artifacts.
- [x] Do not add public C API, public symbols, enum values, result codes, or ABI
  artifact path changes.
- [x] Do not publish Python wheels, Rust crates, or package-manager recipes.
- [x] Do not use cloud, Pro license, network image fetching, remote calculation,
  or Pro/cloud numerical equivalence as a gate.
- [x] Keep `original/ruckig-main` frozen.
