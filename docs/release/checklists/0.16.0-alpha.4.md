# 0.16.0-alpha.4 Public Diagnostics State And Resume Checklist

Status: local evidence complete; ordinary remote push CI is observed after the
checklist commit is pushed.

This slice extends the alpha.3 public diagnostics API without adding public
symbols. It improves `ruckig_update_with_diagnostics` explanations for
interruption and waypoint resume state while keeping legacy `ruckig_update`
behavior, public result-code numeric values, existing public struct layouts,
version metadata, release/tag state, workflow, wrapper publication status,
upstream baseline, and visualization assets unchanged.

## Scope

- [x] Added no-waypoint interruption diagnostics using
  `RUCKIG_DIAGNOSTIC_SCOPE_UPDATE` and `RUCKIG_DIAGNOSTIC_INTERRUPTED`.
- [x] Added waypoint interruption diagnostics using
  `RUCKIG_DIAGNOSTIC_SCOPE_WAYPOINT` and `RUCKIG_DIAGNOSTIC_INTERRUPTED`.
- [x] Added waypoint resume identity mismatch diagnostics using
  `RUCKIG_DIAGNOSTIC_SCOPE_WAYPOINT` and
  `RUCKIG_DIAGNOSTIC_RESUME_IDENTITY_MISMATCH`.
- [x] Added waypoint update count/capacity mismatch diagnostics using the
  stable public `expected_count` and `actual_count` fields.
- [x] Mapped cleared/stale waypoint resume state to the same stable coarse
  resume mismatch code without exposing private identity-field details.
- [x] Kept waypoint branch queues, candidate ordering, solver tie-breaks, and
  resume identity internals private.

## Public API / ABI Boundary

- [x] No public header declaration is added or removed.
- [x] No public symbol is added; the public symbol count remains 188 after the
  alpha.3 core diagnostics expansion.
- [x] `docs/abi/public-symbols.txt` is unchanged in this slice.
- [x] No existing public result-code numeric value changes.
- [x] No existing public struct layout changes.
- [x] No ABI exception file, workflow, version metadata, release/tag state,
  wrapper publication status, upstream baseline, or visualization asset is
  changed.

## Added Tests

- [x] Extended `ruckig_c_public_diagnostics`.
- [x] No-waypoint interruption reports `INTERRUPTED` while preserving the
  original `RUCKIG_WORKING` result.
- [x] Waypoint interruption reports `WAYPOINT + INTERRUPTED`.
- [x] Waypoint resume target mutation reports
  `WAYPOINT + RESUME_IDENTITY_MISMATCH`.
- [x] Waypoint resume limit, per-section, and enabled-DoF mutations report the
  same stable mismatch code.
- [x] Too-small diagnostics passed during an active waypoint resume fails
  before running the operation and does not corrupt the subsequent valid
  resume path.
- [x] Existing interrupt boundary, no-waypoint interrupt, waypoint resume
  stress, and state-machine branch coverage selectors continue to pass.
