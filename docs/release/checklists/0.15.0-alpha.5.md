# 0.15.0-alpha.5 Fast Tracking Sequence Continuation

Status: local alpha implementation complete.

This slice implements Fast-mode behavior for the alpha.4 tracking sequence
continuation API. It keeps the legacy `ruckig_tracking_calculate_sequence`
entry point complete-only and uses the new continuation handle only through
`ruckig_tracking_calculate_sequence_interruptible` and
`ruckig_tracking_resume_sequence`.

## Scope

- [x] Implements Fast `ruckig_tracking_calculate_sequence_interruptible`.
- [x] Implements Fast `ruckig_tracking_resume_sequence`.
- [x] Publishes only complete sequence-step prefixes when the interrupt budget
  expires.
- [x] Keeps the current in-progress step private; no partial step is written to
  `ruckig_tracking_output_sequence_t`.
- [x] Stores target sequence and input snapshots in the continuation handle so
  resume calls do not require the caller to resend target/input data.
- [x] Leaves Optimized sequence continuation to `0.15.0-alpha.6`.
- [x] Leaves Python/Rust wrapper smoke coverage to `0.15.0-alpha.7`.

## Public API / ABI Boundary

- [x] No public symbols added beyond the 184-symbol alpha.4 continuation API

- [x] No public header signature changes beyond the alpha.4 API already

- [x] No enum numeric, result-code numeric, or public diagnostics struct layout
