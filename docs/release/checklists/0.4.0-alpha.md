# Ruckig C 0.4.0 Alpha Checklist

This checklist tracks the `0.4.0-design` alpha line for full original-surface
parity. It is not a stable `v0.4.0` release checklist.

## Scope

- [x] `CHANGELOG.md` has `0.4.0-design - Unreleased`.
- [x] `CMakeLists.txt` and public version macros are on the `0.4.0` design
  line.
- [x] Public C ABI additions are recorded in `docs/abi/public-symbols.txt`.
- [x] Public ABI addition approvals are recorded in
  `docs/abi/public-symbol-exceptions.txt`.
- [x] `docs/design/0.4.0_original_parity.md` records the local optimizer,
  hybrid oracle, no-cloud, and alpha-first decisions.
- [x] `original/ruckig-main` remains unchanged.

## C ABI And Data Model

- [x] Waypoint-aware constructors exist for `ruckig_t`, `ruckig_input_t`,
  `ruckig_output_t`, and `ruckig_trajectory_t`.
- [x] Global max/min position accessors exist.
- [x] Intermediate waypoint set/get/clear APIs exist.
- [x] Per-section max/min velocity, max/min acceleration, max jerk, max/min
  position, and minimum-duration APIs exist.
- [x] Multi-section trajectory section count and intermediate-duration APIs
  exist.
- [x] Deterministic local intermediate-position filtering exists.
- [x] No waypoint optimizer internals are exported as public symbols.
- [x] C examples cover waypoint offline, waypoint online, per-section minimum
  duration, per-section limits, intermediate-position filtering, and dynamic
  DoFs with waypoints.

## Optimizer Alpha

- [x] Waypoint calculation uses a coupled internal waypoint
  velocity/acceleration candidate search.
- [x] Candidate sections are evaluated through the existing target solver.
- [x] Deterministic branch-queue exploration is used for bounded local search
  around the best candidate.
- [x] Position bounds are checked before a candidate is accepted.
- [x] The selected trajectory stores cumulative section times and section
  profiles.
- [x] `trajectory_at_time` samples the correct section.
- [x] Position extrema and first-time-at-position scan all sections.
- [x] Prepared waypoint calculate path is covered by allocation-forbidden C
  tests.
