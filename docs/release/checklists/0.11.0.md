# Ruckig C 0.11.0 Release Checklist

This checklist records the stable `v0.11.0` waypoint soft-interruption and
platform-clock evidence release closeout. The release keeps the `v0.10.0`
172-symbol public C ABI unchanged while adopting waypoint `ruckig_update`
soft-interruption V1 and the internal platform clock abstraction reviewed
during `0.11.0-readiness`.

## Soft Interruption And Platform Clock Evidence

- [x] `v0.11.0` stabilizes `0.11.0-design` waypoint `ruckig_update`
  soft-interruption V1.
- [x] `v0.11.0` stabilizes the internal platform clock abstraction.
- [x] Unset or cleared `interrupt_calculation_duration` disables soft
  interruption.
- [x] `interrupt_calculation_duration = 0.0` interrupts at the first safe
  complete waypoint candidate boundary after a complete feasible candidate is
  available.
- [x] Budget expiry without a complete feasible candidate returns
  `RUCKIG_ERROR_EXECUTION_TIME_CALCULATION` and does not publish an invalid new
  trajectory.
- [x] Normal no-recalculation sampling cycles clear
  `was_calculation_interrupted`.
- [x] Soft interruption does not depend on
  `RUCKIG_C_ENABLE_CALCULATION_DURATION`.
- [x] Custom platform clock providers are compile-time internal hooks only.
- [x] No hard real-time guarantee, cross-cycle continuation, runtime clock
  setter, cloud fallback, or proprietary Pro equivalence claim is made.
