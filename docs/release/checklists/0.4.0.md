# Ruckig C 0.4.0 Release Checklist

This checklist is for the future stable `v0.4.0` release. It must not be used
to publish a stable release until the `0.4.0-design` alpha evidence shows the
local waypoint optimizer is ready for a stable claim.

## Scope Freeze

- [ ] `CHANGELOG.md` has a dated `0.4.0` entry.
- [ ] `README.md` latest release text is updated only after the tag is pushed.
- [ ] `0.4.0` release notes clearly state that the optimizer is local and that
  cloud/remote calculation is not implemented.
- [ ] Existing `v0.3.0` public functions are not removed or signature-changed.
- [ ] Existing enum numeric values and result-code numeric values are unchanged.
- [ ] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
- [ ] Upstream baseline upgrade, cloud API, package-manager publication,
  Python wheels, and Rust crate publication are either completed through
  separate approved scope or explicitly deferred in release notes.

## C ABI Review

- [ ] Public header diff from `v0.3.0` is reviewed:

  ```powershell
  git -c safe.directory=E:/Yww/DownLoad/source/ruckig_c diff v0.3.0 -- include/ruckig_c/ruckig.h
  ```

- [ ] All intentional new public symbols are present in
  `docs/abi/public-symbols.txt`.
- [ ] All intentional `0.4.0` public additions are approved in
  `docs/abi/public-symbol-exceptions.txt`.
- [ ] No optimizer internals are exported.
- [ ] Public symbol allowlist verification passes:

  ```powershell
  cmake --build build_release_check_shared --target ruckig_c_verify_public_symbols
  ```

- [ ] Windows exported-symbol comparison passes with no missing, removed, or
  unapproved public symbols.
- [ ] Linux exported-symbol comparison passes with no missing, removed, or
  unapproved public symbols.
- [ ] macOS exported-symbol snapshot is reviewed against the public allowlist.

## Waypoint Optimizer Evidence

- [ ] Waypoint-aware constructors, storage, setters/getters, validation, and
  clear behavior are covered by C tests.
- [ ] Intermediate positions require position control.
- [ ] Waypoint mode rejects global minimum duration, discrete duration,
  per-DoF control/synchronization overrides, infinite jerk limits, and invalid
  disabled-DoF movement.
- [ ] Per-section vector constraints require `waypoint_count + 1` sections.
- [ ] Per-section max/min sign and bound semantics are covered.
- [ ] Multi-section `trajectory_at_time` samples the correct section.
- [ ] `position_extrema` and `first_time_at_position` scan all sections.
- [ ] Prepared waypoint calculate/update paths do not allocate in normal use.
- [ ] Fixed waypoint regression corpus passes.
- [ ] Optimizer quality tests prove accepted alpha durations do not regress
  against the zero-derivative segment baseline.
- [ ] Section-level oracle tests compare accepted section inputs against the
  frozen original target solver.
- [ ] Optional cloud/Pro black-box comparison evidence, if available, is
  recorded as non-blocking evidence and not as a runtime dependency.

## Wrapper Scope

- [ ] Python `cffi` prototype covers the stable `0.4.0` C ABI or is explicitly
  deferred from the release notes.
- [ ] Python wheels are not claimed unless a separate wheel packaging project
  completes.
- [ ] Rust alpha wrapper covers the stable `0.4.0` C ABI or is explicitly
  deferred from the release notes.
- [ ] Rust crate publication is not claimed unless a separate crate release
  project completes.

## Performance Evidence

- [ ] Windows no-waypoint benchmark `--samples 10000 --seed 1` is below the
  average C/oracle ratio threshold `<= 1.5`.
- [ ] Linux no-waypoint benchmark `--samples 10000 --seed 1` is below the
  average C/oracle ratio threshold `<= 1.5`.
- [ ] Windows waypoint alpha benchmark `--samples 10000 --seed 1 --waypoints`
  is recorded as C-only local optimizer trend evidence.
- [ ] Linux waypoint alpha benchmark `--samples 10000 --seed 1 --waypoints` is
  recorded as C-only local optimizer trend evidence.
- [ ] `docs/release/evidence/performance_report.md` records OS, CPU, compiler,
  generator, build type, samples, seed, average, p99, and worst timings.

## Release Closeout

- [ ] Stable readiness decision says `v0.4.0` can claim local waypoint optimizer
  readiness, or the release is kept on another alpha cycle.
- [ ] Release evidence commit is final.
- [ ] Tag `v0.4.0` points to the final release evidence commit.
- [ ] GitHub Release notes include final commit hash, CI run id, manual release
  random run id, fixed oracle count, waypoint corpus summary, ABI/exported
  symbol summary, performance summary, wrapper scope, and deferred features.
