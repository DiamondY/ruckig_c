# Ruckig C 0.4.0 Release Checklist

This checklist records the `v0.4.0` original-surface parity release closeout.
`0.4.0` intentionally expands the public C ABI for local waypoint optimization,
per-section constraints, global position bounds, and multi-section trajectory
queries. It does not implement cloud or remote calculation, does not publish
Python wheels, does not publish a Rust crate, does not add package-manager
recipes, and does not update the frozen upstream oracle baseline.

## Scope

- [x] Version is `0.4.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.4.0`.
- [x] `CHANGELOG.md` has a dated `0.4.0` release entry.
- [x] `README.md` describes `v0.4.0` as the current original-surface parity
  release line and keeps wrapper/package publication out of stable scope.
- [x] Release notes clearly state that the optimizer is local and that
  cloud/remote calculation is not implemented.
- [x] Existing `v0.3.0` public functions are not removed or signature-changed.
- [x] Existing enum numeric values and result-code numeric values are unchanged.
- [x] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
- [x] Upstream baseline upgrade, cloud API, package-manager publication,
  Python wheels, and Rust crate publication are explicitly deferred.

## Waypoint Optimizer Evidence

- [x] Waypoint-aware constructors, storage, setters/getters, validation, and
  clear behavior are covered by C tests.
- [x] Intermediate positions require position control.
- [x] Waypoint mode rejects global minimum duration, discrete duration,
  per-DoF control/synchronization overrides, infinite jerk limits, and invalid
  disabled-DoF movement.
- [x] Per-section vector constraints require `waypoint_count + 1` sections.
- [x] Per-section max/min sign and bound semantics are covered.
- [x] Multi-section `trajectory_at_time` samples the correct section.
- [x] `position_extrema` and `first_time_at_position` scan all sections.
- [x] Prepared waypoint calculate/update paths do not allocate in normal use.
- [x] Fixed waypoint regression corpus passes.
- [x] Optimizer quality tests prove accepted alpha durations do not regress
  against the zero-derivative segment baseline.

  frozen original target solver.
- [x] Optional cloud/Pro black-box comparison evidence is not available and is
  not a runtime dependency.
