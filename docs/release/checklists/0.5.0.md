# Ruckig C 0.5.0 Release Checklist

This checklist records the stable `v0.5.0` tracking release closeout. The
release stabilizes the public C tracking ABI added on the `0.5.0-design` line
and ships local Fast-mode online/offline tracking. `RUCKIG_TRACKING_OPTIMIZED`
remains declared for API shape parity but returns `RUCKIG_ERROR_UNSUPPORTED`
throughout `0.5.x`.

## Scope

- [x] Version is `0.5.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.5.0`.
- [x] `CHANGELOG.md` has a dated `0.5.0` release entry.
- [x] `README.md` describes `v0.5.0` as the current stable release.
- [x] `docs/current/roadmap.md` records `v0.5.0` as the stable Fast-only
  tracking release and `0.6.0-design` as the next design line.
- [x] Existing `v0.4.2` public functions are not removed or signature-changed.
- [x] Existing enum numeric values and result-code numeric values are
  unchanged.
- [x] The public C tracking ABI is stabilized in `v0.5.0`.
- [x] Local Fast-mode online/offline tracking is included.
- [x] `Optimized` tracking implementation is deferred to `0.6.0-design` and is
  not aliased to Fast.
- [x] Python `cffi` remains prototype-only; no wheel is published.
- [x] Rust remains an alpha wrapper; no crate is published.
