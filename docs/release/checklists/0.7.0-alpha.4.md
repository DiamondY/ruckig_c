# Ruckig C 0.7.0 Alpha.4 Solver Branch Coverage Checklist

This checklist records the `0.7.0-alpha.4` targeted solver branch coverage
evidence on the `0.7.0-design - Unreleased` line. It is not a stable
`v0.7.0` release checklist, does not create a tag, and does not create a
GitHub Release.

## Targeted Coverage Changes

- [x] Added six fixed frozen C++ oracle cases for targeted second-order
  position and third-order velocity branch families:
  `position-second-order-nonzero-target-velocity`,
  `position-second-order-stretched-nonzero-velocity`,
  `position-second-order-2d-step2-time-sync`,
  `velocity-third-order-nonzero-target-acceleration`,
  `velocity-third-order-negative-stretched`, and
  `velocity-third-order-2d-step2-time-sync`.
- [x] Added `ruckig_c_tests --solver-branch-coverage`.
- [x] Added CTest gate `ruckig_c_solver_branch_coverage`.
- [x] Added internal white-box branch probes for `block.c` covering invalid
  inputs, 1/2/3/4/5-profile candidate sets, tie-breaks, duplicate removal,
  blocked intervals, and profile selection.
- [x] Added internal direct branch probes for second-order position and
  third-order velocity step setup/timing paths. These probes are coverage
  hardening only; original behavior parity remains backed by frozen C++ oracle
  comparisons.
- [x] `tools/coverage/run_coverage.ps1` defaults to
  `0.7.0-alpha.4` while retaining the `-CoverageLabel` override.
