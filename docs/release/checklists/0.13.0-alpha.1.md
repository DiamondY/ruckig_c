`0.13.0-design - Unreleased` line. It is not a stable `v0.13.0` release
closeout.

## Added Local Coverage

- [x] Added `--waypoint-resume-stress` to `ruckig_c_tests`.
- [x] Added CTest entry `ruckig_c_waypoint_resume_stress`.
- [x] Added a 4-DoF, three-waypoint resume stress case with per-section
  velocity, acceleration, jerk, position, and minimum-duration constraints.
- [x] Covered interrupt-budget matrix behavior for zero budget, a tiny
  positive budget, zero-budget continuation, a large completion budget,
  runtime budget changes, and interrupt clear.
- [x] Covered background interrupted-without-publish semantics: the old
  trajectory keeps sampling, `new_calculation=false`, and
  `was_calculation_interrupted=true`.
- [x] Covered background publish semantics: published trajectories must be
  complete, feasible, time-reset through normal new-calculation sampling, and
  better than incumbent remaining duration.
- [x] Recorded fresh full-solve quality references for the current remaining
  input during active resume cycles without requiring equality with the
  resumed result.
- [x] Expanded allocation guard coverage to initial interrupted update,
  background interrupted-without-publish, and background completion/publish
  paths.
