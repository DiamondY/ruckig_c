# Ruckig C 0.5.0 Alpha Checklist

This checklist tracks the `0.5.0-design` tracking API and local Fast-mode
alpha evidence. It is not a stable `v0.5.0` release checklist. `v0.4.2`
remains the latest stable release until a deliberate release closeout.

- [x] `CHANGELOG.md` records `0.5.0-design - Unreleased`.
- [x] `README.md` keeps `v0.4.2` as the current stable release and describes

## C Tracking Implementation

- [x] `ruckig_tracking_t` owns preallocated internal `ruckig_t`,
  `ruckig_input_t`, and `ruckig_output_t` workspace.
- [x] `ruckig_target_state_t` owns position, velocity, and acceleration arrays.
- [x] `ruckig_target_state_sequence_t` owns preallocated flat
  `capacity * dofs` position, velocity, and acceleration arrays.
- [x] `ruckig_tracking_output_sequence_t` owns preallocated flat output arrays,
  time, section, and result arrays.
- [x] Online Fast tracking uses constant-acceleration lookahead:
  `h = look_ahead_cycles * delta_time * reactiveness`.
- [x] `reactiveness` must be finite and in `[0, 1]`.
- [x] `look_ahead_cycles` must be at least `1`.
- [x] Target values must be finite.
- [x] DoF mismatches return `RUCKIG_ERROR_INVALID_INPUT`.
- [x] Velocity-control tracking and per-DoF control-interface overrides are
  rejected in the first alpha.
- [x] Online update does not mutate the caller input; callers still use
  `ruckig_output_pass_to_input`.
- [x] Offline sequence calculation writes only complete successful steps and
  records the number of written steps in the output sequence count.
- [x] No public diagnostic getters are added.
- [x] `interrupt_calculation_duration` does not participate in tracking timeout
  behavior in this alpha.
