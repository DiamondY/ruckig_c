# Ruckig C 0.7.0 Alpha.2 Tracking Diagnostics Checklist

This checklist records the `0.7.0-alpha.2` tracking diagnostics and quality
hardening evidence on the `0.7.0-design - Unreleased` line. It is not a stable
`v0.7.0` release checklist, does not create a tag, and does not create a
GitHub Release.

## Scope

- [x] `CHANGELOG.md` records `0.7.0-alpha.2` diagnostics and quality hardening
  scope.
- [x] `docs/design/tracking_optimized_mode.md` records the accepted diagnostics
  snapshot API, score summary, candidate-family counters, quality gates, stress
  gates, no-allocation policy, and deferred items.
- [x] `README.md`, `docs/current/roadmap.md`, and
  `docs/current/original_parity_coverage.md` distinguish stable `v0.6.0`
  Optimized tracking from `main`'s `0.7.0-alpha.2` evidence.
- [x] No stable tag, prerelease tag, or GitHub Release is created from this
  alpha evidence.
- [x] No cloud, remote calculation, Pro sample, network dependency, or
  external license is used as a gate.
- [x] Soft interruption checkpoints, formal Python/Rust publication,
  package-manager recipes, cloud/remote calculation, Pro/cloud equivalence
  claims, and upstream baseline upgrade remain deferred.
- [x] `original/ruckig-main` remains frozen.

## Public C ABI Review

- [x] Existing `v0.6.0` and `0.7.0-alpha` public functions and signatures are
  not removed or modified.
- [x] Existing enum numeric values and result-code numeric values are
  unchanged.
- [x] New public symbols are limited to the approved diagnostics getter:
  `ruckig_tracking_get_last_diagnostics`.
- [x] `ruckig_tracking_diagnostics_t` is additive and uses named
  candidate-family counters, score fields, aggregate step counters, and zeroed
  reserved fields.
- [x] `docs/abi/public-symbols.txt` contains 172 approved public symbols.
- [x] `docs/abi/public-symbol-exceptions.txt` records the approved
  `0.7.0-alpha.2` addition.
- [x] ABI artifact paths use `artifacts/abi/0.7.0-alpha.2`.
- [x] Public symbol allowlist verification passes.
- [x] Public exported-symbol comparison passes.
- [x] Public header diff against `v0.6.0` is reviewed and limited to approved
  strategy and diagnostics API additions plus comments.

## Diagnostics Evidence

- [x] Diagnostics getter rejects `NULL` arguments.
- [x] Default pre-calculation snapshot reports `NONE`, current mode/strategy,
  zero counters, zero scores, and zeroed reserved fields.
- [x] Fast online diagnostics report `FAST`, one Fast candidate, one valid
  candidate, and zero scores.
- [x] Fast offline diagnostics aggregate one Fast candidate per target sample.
- [x] Optimized online diagnostics report score summary, family counters,
  budget exhaustion, and one step classified as Optimized or Fast fallback.
- [x] Optimized offline diagnostics aggregate candidate counts and per-step
  fallback/optimized/error counters.
- [x] Legacy getters
  `ruckig_tracking_get_last_calculation_status` and
  `ruckig_tracking_get_last_candidate_count` read the same finalized
  diagnostics state.
- [x] Prepared Fast and Optimized online/offline diagnostics paths are covered
  by no-allocation tests.

## Quality and Stress Evidence

- [x] Balanced weighted tracking error is not worse than Fast baseline on fixed
  ramp, constant-acceleration, sinus, and half-sinus cases within tolerance.
- [x] Balanced improves by at least `0.5%` on selected smooth lookahead cases.
- [x] Aggressive improves over Balanced by at least `2%` on fixed oscillatory
  cases.
- [x] Routine CTest stress includes:
  `ruckig_c_tests --tracking-random 100000 --seed 1`,
  `--seed 2`, and `--seed 41`.
- [x] Manual stress includes:
  `ruckig_c_tests --tracking-random 1000000 --seed 1`.
