# Ruckig C 0.9.0 Release Checklist

This checklist records the stable `v0.9.0` tracking quality and stability
evidence release closeout. The release keeps the `v0.8.0` 172-symbol public C
ABI unchanged while adopting the tracking audit, tuned evaluator hardening, and
stability regression evidence reviewed during `0.9.0-readiness`.

## Scope

- [x] Version is `0.9.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.9.0`.
- [x] `CHANGELOG.md` has a dated `0.9.0` release entry.
- [x] `README.md` describes `v0.9.0` as the current stable release.
- [x] `docs/current/roadmap.md` records `v0.9.0` as the stable tracking
  quality/stability evidence release.
- [x] Existing `v0.8.0` public functions are not removed or signature-changed.
- [x] Existing enum numeric values and result-code numeric values are
  unchanged.
- [x] Public symbol count remains `172`.
- [x] Public additions in `v0.9.0`: `0`.
- [x] Public removals in `v0.9.0`: `0`.
- [x] `--tracking-random` behavior and output remain unchanged.
- [x] `--tracking-random-audit`, `--tracking-quality-hardening`, and
  `--tracking-stability` remain test-runner evidence surfaces only.
- [x] Python `cffi` remains prototype-only; no wheel is published.
- [x] Rust remains an alpha wrapper; no crate is published.
- [x] Package-manager recipes remain deferred.
- [x] No Pro/cloud sample, network dependency, or external license is used as a
  release gate.
- [x] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
