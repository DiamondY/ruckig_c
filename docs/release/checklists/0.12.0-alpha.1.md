# Ruckig C 0.12.0-alpha.1 Waypoint Soft-Interruption True Resume Checklist

This checklist records the local `0.12.0-alpha.1` evidence slice on the
`0.12.0-design - Unreleased` line. It is not a stable `v0.12.0` release
closeout.

## Scope

- [x] Current stable release remains `v0.11.0`.
- [x] Current `main` remains `0.12.0-design - Unreleased`.
- [x] The slice is limited to intermediate-waypoint `ruckig_update` soft
  interruption.
- [x] Public `ruckig_calculate` remains a complete waypoint calculation path
  even when `interrupt_calculation_duration` is set.
- [x] No-waypoint target solving and tracking remain outside soft-interruption
  resume scope.
- [x] No public C ABI, public header signature, enum numeric value, result-code
  numeric value, or exported symbol is added.
- [x] Runtime platform-clock public hooks remain deferred.
- [x] Package-manager recipes/publication, Cloud/remote runtime, Pro/cloud
  equivalence claims, hard real-time claims, and formal global optimality
  claims remain out of scope.
- [x] No version bump, tag, GitHub Release, or manual release-random workflow
  is part of this alpha evidence slice.
- [x] `original/ruckig-main` remains frozen and unmodified.

## Implemented Behavior

- [x] Interrupted waypoint `ruckig_update` calculations keep private optimizer
  resume state after publishing the first complete feasible candidate.
- [x] Private resume state stores the search phase and complete-candidate
  cursors for baseline, finite-difference, refine, and branch-search work.
- [x] Branch queue storage is preallocated with the `ruckig_t` handle and does
  not allocate during online update/resume.
- [x] Background online cycles continue optimizer work only after normal
  `ruckig_output_pass_to_input` progression and matching private planning
  identity.
- [x] Background publish happens only for a complete feasible candidate that is
  better than the old trajectory's remaining duration.
- [x] Publishing a background candidate follows normal new-calculation output
  semantics: `new_calculation=true`, output time/section reset, then the cycle
  samples at `delta_time`.
- [x] Background interruption without a publishable candidate keeps sampling
  the old trajectory and returns `RUCKIG_WORKING`.
- [x] Clearing the interrupt field, changing planning identity, providing a
  non-normal current state, or calling `ruckig_reset` invalidates private
  resume state.
