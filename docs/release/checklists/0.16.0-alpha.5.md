# 0.16.0-alpha.5 Tracking Public Diagnostics Getter Checklist

Status: local evidence complete; ordinary remote push CI is observed after
the checklist commit is pushed.

This slice completes the staged public diagnostics API shape by adding generic
public diagnostics getters for tracking and tracking sequence continuation. It
does not add `_with_diagnostics` variants to individual tracking operations and
does not expose private candidate ordering, scoring, solver profile branches,
or waypoint queue internals.

## Scope

- [x] Added `ruckig_tracking_get_last_public_diagnostics`.
- [x] Added
  `ruckig_tracking_sequence_continuation_get_last_diagnostics`.
- [x] Kept the existing specialized
  `ruckig_tracking_get_last_diagnostics` snapshot API unchanged.
- [x] Mapped tracking calculation status to stable coarse public diagnostics:
  success states use `RUCKIG_DIAGNOSTIC_NONE`, budget exhaustion maps to
  `RUCKIG_DIAGNOSTIC_INTERRUPTED`, and error state maps to
  `RUCKIG_DIAGNOSTIC_UNSUPPORTED`.
- [x] Mapped continuation state to stable public diagnostics for
  empty/unstarted, interrupted, complete, and error states.
- [x] Exposed only continuation counts that are already available through
  public accessors: `target_count` and `completed_count`.
