# 0.8.0-alpha.2 Matplotlib Visualization Evidence Checklist

This checklist records the `0.8.0-alpha.2` visualization evidence slice on
`0.8.0-design - Unreleased`. It is not a stable release closeout, does not
create a tag or GitHub Release, and does not add public C API.

## Scope

- [x] Replace the first Pillow-only gallery renderer with NumPy and
  Matplotlib `Agg`.
- [x] Generate and commit PNG-only `ruckig_c`-owned assets under
  `docs/assets/visualization/`.
- [x] Replace the previous six Pillow PNGs rather than keeping dual asset
  tracks.
- [x] Cover local C ABI equivalents of original examples `01-10` and `14-16`.
- [x] Exclude original examples `11-13` because they are C++ Eigen/custom-vector
  ergonomics examples, not C ABI visualization behavior.
- [x] Generate a deterministic `manifest.json` with asset names, titles,
  original example mapping, metrics, byte counts, and SHA-256 hashes.
- [x] Avoid manifest timestamps, virtualenv paths, local absolute paths, raw
  sample data, PDF, and SVG output.
- [x] Keep visualization local-only and outside default GitHub Actions gates.
- [x] Do not copy original Ruckig images or PDFs as primary project evidence.
- [x] Do not add public C API, public symbols, enum values, result codes, or
  ABI artifact path changes.
- [x] Do not publish Python wheels, Rust crates, or package-manager recipes.
- [x] Do not use cloud, Pro license, network image fetching, remote
  calculation, or Pro/cloud numerical equivalence as a gate.
- [x] Keep `original/ruckig-main` frozen.
