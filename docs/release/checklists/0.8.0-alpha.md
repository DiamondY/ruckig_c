# 0.8.0-alpha Visualization Evidence Checklist

This checklist records the first post-`v0.7.0` visualization evidence slice on
`0.8.0-design - Unreleased`. It is not a stable release closeout, does not
create a tag or GitHub Release, and does not add public C API.

## Scope

- [x] Add a local gallery generator under `tools/visualization/`.
- [x] Generate `ruckig_c`-owned PNG assets under
  `docs/assets/visualization/`.
- [x] Generate a deterministic `manifest.json` with asset hashes and scenario
  metrics.
- [x] Document the generation command and evidence boundaries in
  `docs/current/visualization.md`.
- [x] Keep visualization local-only and outside default GitHub Actions gates.
- [x] Do not copy original Ruckig images or PDFs as primary project evidence.
- [x] Do not add public C API, public symbols, enum values, result codes, or
  ABI artifact path changes.
- [x] Do not publish Python wheels, Rust crates, or package-manager recipes.
- [x] Do not use cloud, Pro license, network fetching, or Pro/cloud numerical
  equivalence as a gate.
- [x] Keep `original/ruckig-main` frozen.

## Generated Assets

Command:

```powershell
$env:RUCKIG_C_SHARED_LIBRARY=(Resolve-Path out\build\windows-clang-ninja-shared\ruckig_c.dll).Path
python tools\visualization\generate_gallery.py --output docs\assets\visualization
```

Gallery scenarios:

- no-waypoint position trajectory sampled with `ruckig_trajectory_at_time`;
- velocity-control trajectory;
- stop trajectory;
- minimum-duration constrained trajectory;
- two-DoF local waypoint trajectory with intermediate section timing;
- online Fast vs bounded Optimized tracking comparison with diagnostics
  summary.
