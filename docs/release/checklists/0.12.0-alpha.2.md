# Ruckig C 0.12.0-alpha.2 True-Resume Unified Engine Hardening Checklist

This checklist records the local `0.12.0-alpha.2` evidence slice on the
`0.12.0-design - Unreleased` line. It is not a stable `v0.12.0` release
closeout.

## Scope

- [x] Current stable release remains `v0.11.0`.
- [x] Current `main` remains `0.12.0-design - Unreleased`.
- [x] `0.12.0-alpha.1` remote push CI evidence was already recorded before
  this slice.
- [x] The slice is limited to intermediate-waypoint `ruckig_update` soft
  interruption and complete waypoint solving internals.
- [x] No public C ABI, public header signature, enum numeric value,
  result-code numeric value, or exported symbol is added.
- [x] Public `ruckig_calculate` remains complete and non-interruptible even
  when `interrupt_calculation_duration` is set.
- [x] No-waypoint target solving and tracking remain outside
  soft-interruption scope.
- [x] Package-manager recipes/publication, Cloud/remote runtime, Pro/cloud
  equivalence claims, hard real-time claims, and formal global optimality
  claims remain out of scope.
- [x] No version bump, tag, GitHub Release, or manual release-random workflow
  is part of this alpha evidence slice.

## Implemented Behavior

- [x] Complete waypoint solving and interruptible waypoint resume now share the
  private step-driven waypoint optimizer engine.
- [x] Full waypoint calculations run the step-driven engine without an
  interrupt context until completion, then clear active private resume state.
- [x] The unified engine preserves the established complete-solve candidate
  order and branch-search budget semantics.
- [x] Waypoint `ruckig_update` with an interrupt budget keeps V2 background
  continuation and publish semantics.
- [x] Changing only `interrupt_calculation_duration` changes the current cycle
  budget without invalidating the private resume state.
- [x] Clearing the interrupt field disables soft interruption and clears
  private resume state.
- [x] Branch queue storage remains preallocated with the `ruckig_t` handle and
  is used by both full and interruptible waypoint solving.

## Added Local Coverage

- [x] Public waypoint `ruckig_calculate` ignores the interrupt field, completes
  through the unified engine, and leaves no active resume.
- [x] Waypoint `ruckig_update` without an interrupt budget completes through
  the unified engine and leaves no active resume.
- [x] Multi-DoF and multi-waypoint interrupted update resumes across
  `pass_to_input`, with per-section constraints checked on published
  trajectories.
- [x] Background completion after an interrupt-duration change runs under the
  allocation guard.
- [x] A fresh full solve of the current remaining input is compared as quality
  evidence while publish acceptance remains incumbent-improvement based.
- [x] Long zero-budget online loops preserve valid sampling when no publish
  occurs and use normal new-calculation time reset when publishing.
- [x] Invalidation matrix covers target, intermediate positions, waypoint
  count, limits, per-section constraints, enabled DoFs, synchronization,
  invalid control mode, invalid duration discretization, and interrupt clear.
- [x] Active resume state is isolated from public `ruckig_calculate` and
  no-waypoint `ruckig_update`.
