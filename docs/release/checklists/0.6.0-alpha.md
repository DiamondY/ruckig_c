# Ruckig C 0.6.0 Alpha Optimized Tracking Checklist

This checklist records the `0.6.0-alpha` Optimized tracking MVP evidence on
the `0.6.0-design - Unreleased` line. It is not a stable `v0.6.0` release
checklist, does not create a prerelease tag, and does not claim Pro/cloud
numerical equivalence.

## Scope

- [x] `CHANGELOG.md` records `0.6.0-design - Unreleased` Optimized tracking
  alpha scope.
- [x] `docs/design/tracking_optimized_mode.md` records the accepted alpha API,
  objective, fallback, diagnostics, no-allocation, and evidence policy.
- [x] `README.md`, `docs/current/roadmap.md`, and
  `docs/current/original_parity_coverage.md` distinguish stable `v0.5.0`
  Fast-only tracking from `main`'s `0.6.0-alpha` Optimized tracking evidence.
- [x] No stable `v0.6.0` tag or GitHub Release is created from this alpha
  evidence.
- [x] No cloud, remote calculation, Pro sample, network dependency, or external
  license is used as a gate.
- [x] Soft interruption checkpoints, formal Python/Rust publication,
  package-manager recipes, cloud/remote calculation, Pro/cloud equivalence
  claims, and upstream baseline upgrade remain deferred.
- [x] `original/ruckig-main` remains frozen.

## Public C ABI Review

- [x] Existing `v0.5.0` public functions and signatures are not removed or
  modified.
- [x] Existing enum numeric values and result-code numeric values are

- [x] New public symbols are limited to the approved Optimized tracking alpha

  `ruckig_tracking_set_max_optimized_candidates`,
  `ruckig_tracking_get_max_optimized_candidates`,
  `ruckig_tracking_get_last_calculation_status`,

  `ruckig_tracking_update_with_lookahead`.
- [x] `docs/abi/public-symbols.txt` contains 169 approved public symbols.
- [x] `docs/abi/public-symbol-exceptions.txt` records the approved
  `0.6.0-design` additions.
- [x] ABI artifact paths use `artifacts/abi/0.6.0-alpha`.
- [x] Public symbol allowlist verification passes.
- [x] Public exported-symbol comparison passes.
- [x] Public header diff against `v0.5.0` is reviewed and limited to approved
  Optimized tracking API additions and comments.

## Optimized Tracking Evidence

- [x] C implementation supports Optimized single-target update.
- [x] C implementation supports online lookahead through
  `ruckig_tracking_update_with_lookahead`.
- [x] C implementation supports offline Optimized sliding-window sequence
  calculation.
- [x] Default candidate budget is `16`; valid range is `1..128`.
- [x] Fast fallback returns normal control-flow results and is observable
  through `ruckig_tracking_get_last_calculation_status`.
- [x] Offline diagnostic status aggregates all steps.
- [x] Invalid inputs and infeasible baseline errors use existing result codes;
  no public result enum is added.
- [x] Prepared Optimized online/offline paths are covered by no-allocation
  tests.
- [x] Fixed quality gate verifies Optimized objective is not worse than Fast
  baseline on the hard constant-acceleration case.
- [x] Sinus/half-sinus style behavior remains trend evidence, not a hard alpha
  gate.
- [x] C examples cover online Optimized lookahead, online Optimized sinus, and
  offline Optimized sequence.
