# Ruckig C 0.7.0 Release Readiness Checklist

This checklist records the `0.7.0-readiness` evidence audit on the
`0.7.0-design - Unreleased` line. It is not a stable `v0.7.0` release
checklist, does not bump versions, does not create a tag, and does not create
a GitHub Release.

## Readiness Conclusion

Local readiness gates are clean for entering a later `v0.7.0` stable closeout
decision. The future closeout still needs a separate release plan that bumps
`CMakeLists.txt`, updates `RUCKIG_C_VERSION_*` macros, moves ABI artifact paths
to `artifacts/abi/0.7.0`, creates stable release notes/checklists, runs release
candidate and final CI, dispatches manual release-random workflows, creates the
annotated `v0.7.0` tag, publishes the GitHub Release, and moves `main` to the
next design line. Algorithm visualization and trajectory gallery generation are
not part of that closeout; they remain a post-`v0.7.0` documentation/evidence
project so the stable release does not gain plotting dependencies or generated
image/PDF artifacts.
