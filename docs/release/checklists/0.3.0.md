# Ruckig C 0.3.0 Release Checklist

This checklist records the `v0.3.0` hardening-release closeout gates and
evidence. `0.3.0` does not add public C API, does not change solver scope, does
not publish bindings, does not add package-manager recipes, and does not update
the frozen upstream oracle baseline.

## Scope

- [ ] Final release commit hash recorded.
- [ ] Version is `0.3.0` in `CMakeLists.txt` if a `v0.3.0` tag is being cut.
- [ ] Version macros in `include/ruckig_c/ruckig.h` are `0.3.0` if a
  `v0.3.0` tag is being cut.
- [ ] `CHANGELOG.md` has a dated `0.3.0` release entry.
- [ ] `docs/design/0.3.0_release_decision.md` records `0.3.0` as a hardening
  release.
- [ ] Public header diff reviewed against `v0.2.5`.
- [ ] Public header diff contains only approved version macro or documentation
  changes.
- [ ] No public C function additions, removals, or signature changes.
- [ ] No `RUCKIG_C_API` public symbol additions.
- [ ] Result-code and enum numeric values unchanged.
- [ ] `docs/abi/public-symbols.txt` unchanged unless separately approved.
- [ ] `docs/abi/public-symbol-exceptions.txt` remains empty.
- [ ] Strict Linux/Windows public exported-symbol comparison remains
  trial/evidence mode, not routine CI hard failure.
- [ ] macOS exported-symbol evidence is recorded as a `0.3.0` baseline
  bootstrap, not a historical `v0.2.5` diff.
- [ ] Intermediate waypoints remain unsupported.
- [ ] Per-section constraints remain unsupported.
- [ ] Cloud calculation remains unsupported.
- [ ] Python prototype remains feasibility evidence only: not installed, not
  published, not packaged, and not routine CI.
- [ ] Rust bindings remain deferred.
- [ ] Package-manager recipes and new package-manager prototypes remain frozen.
- [ ] MSVC `cl` static/DLL consumer smokes remain optional local gates, not
  routine CI.
- [ ] `original/ruckig-main` remains frozen as the Ruckig Community `0.17.3`
  oracle baseline.

## Required Gates

- [ ] `git status --short --ignored` is clean before release closeout edits.
- [ ] Windows default preset configures, builds, and tests successfully:
  `cmake --preset windows-clang-ninja`,
  `cmake --build --preset windows-clang-ninja`,
  `ctest --preset windows-clang-ninja`.
- [ ] Windows shared preset configures, builds, and tests successfully:
  `cmake --preset windows-clang-ninja-shared`,
  `cmake --build --preset windows-clang-ninja-shared`,
  `ctest --preset windows-clang-ninja-shared`.
- [ ] `ruckig_c_verify_public_symbols` passes.
- [ ] `ruckig_c_compare_public_exported_symbols` produces clean
  warning/evidence output locally.
- [ ] Fixed C++ oracle suite passes and reports the final case count.
- [ ] Development random oracle passes.
- [ ] Manual release random oracle passes with `release_random=true`.
- [ ] Linux performance benchmark average ratio is `<= 1.5`.
- [ ] GitHub Actions push CI passes for the release evidence commit.
- [ ] Linux Clang ASan+UBSan passes.
- [ ] Linux Valgrind passes.
- [ ] Installed CMake consumer smoke test passes.
- [ ] Unix pkg-config consumer smoke test passes where `pkg-config` is
  available.
- [ ] Unix shared install-tree consumer test passes where `pkg-config` is
  available.
- [ ] Windows clang-cl static C-only path passes in CI.
- [ ] Windows clang-cl shared C-only path passes in CI.
- [ ] Windows clang oracle path passes in CI.
- [ ] Windows MinGW static consumer passes in routine CI.
- [ ] Windows MinGW DLL consumer passes in routine CI.
- [ ] MSVC `cl` standalone static smoke remains locally verified or explicitly
  documented as optional local evidence.
- [ ] MSVC `cl` standalone DLL smoke remains locally verified or explicitly
  documented as optional local evidence.
- [ ] Linux exported-symbol artifact uploaded and reviewed.
- [ ] Windows exported-symbol artifact uploaded and reviewed.
- [ ] macOS exported-symbol artifact uploaded and reviewed as bootstrap
  evidence.
- [ ] Python prototype smoke passes with `RUCKIG_C_SHARED_LIBRARY` pointing to
  the Windows shared build.
- [ ] `scripts/clean-local.ps1` dry run reviewed.
- [ ] `scripts/clean-local.ps1 -Apply` removes only ignored local artifacts.
- [ ] Final `git status --short --ignored` contains only expected tracked
  release-preparation files and ignored artifacts required for evidence, or is
  clean after cleanup.

final release closeout commit.
