# Ruckig C 0.3.0 Release Checklist

This checklist records the `v0.3.0` hardening-release closeout gates and
evidence. `0.3.0` does not add public C API, does not change solver scope, does
not publish bindings, does not add package-manager recipes, and does not update
the frozen upstream oracle baseline.

## Scope

- [x] Release evidence commit hash recorded; final tag target is recorded by
  the annotated tag and GitHub Release.
- [x] Version is `0.3.0` in `CMakeLists.txt` if a `v0.3.0` tag is being cut.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.3.0` if a
  `v0.3.0` tag is being cut.
- [x] `CHANGELOG.md` has a dated `0.3.0` release entry.
- [x] `docs/design/0.3.0_release_decision.md` records `0.3.0` as a hardening
  release.
- [x] Public header diff reviewed against `v0.2.5`.
- [x] Public header diff contains only approved version macro or documentation
  changes.
- [x] No public C function additions, removals, or signature changes.
- [x] No `RUCKIG_C_API` public symbol additions.
- [x] Result-code and enum numeric values unchanged.
- [x] `docs/abi/public-symbols.txt` unchanged unless separately approved.
- [x] `docs/abi/public-symbol-exceptions.txt` remains empty.
- [x] Strict Linux/Windows public exported-symbol comparison remains
  trial/evidence mode, not routine CI hard failure.
- [x] macOS exported-symbol evidence is recorded as a `0.3.0` baseline
  bootstrap, not a historical `v0.2.5` diff.
- [x] Intermediate waypoints remain unsupported.
- [x] Per-section constraints remain unsupported.
- [x] Cloud calculation remains unsupported.
- [x] Python prototype remains feasibility evidence only: not installed, not
  published, not packaged, and not routine CI.
- [x] Rust bindings remain deferred.
- [x] Package-manager recipes and new package-manager prototypes remain frozen.
- [x] MSVC `cl` static/DLL consumer smokes remain optional local gates, not
  routine CI.
- [x] `original/ruckig-main` remains frozen as the Ruckig Community `0.17.3`
  oracle baseline.
