# 0.9.0-alpha.2 Tracking Quality Hardening Evidence Checklist

This checklist records the `0.9.0-alpha.2` tracking Optimized evaluator quality
hardening evidence on `0.9.0-design - Unreleased`. It is not a stable release
closeout and does not create a tag or GitHub Release.

## Scope

- [x] Tune the bounded local Optimized tracking evaluator after the alpha.1
  fallback audit.
- [x] Add private candidate-family attribution fields to opaque
  `ruckig_tracking_t` only.
- [x] Keep Stable and Balanced on strict tuned-evaluator-score improvement.
- [x] Add Aggressive near-tie acceptance only for candidates within `1%` of
  Fast raw score and with terminal position error at most half of Fast.
- [x] Add `ruckig_c_tests --tracking-quality-hardening`.
- [x] Add routine CTest `ruckig_c_tracking_quality_hardening`.
- [x] Keep existing `--tracking-random N --seed S` behavior and output
  unchanged.
- [x] Keep `--tracking-random-audit` as test-runner surface only.
- [x] Do not add public C API, public symbols, enum values, result-code values,
  ABI exception entries, or ABI artifact path changes.
- [x] Keep Python/Rust prototype-only; no wheel or crate publication.
- [x] Keep package-manager recipes, visualization v2, soft interruption,
  cloud/remote calculation, Pro/cloud equivalence, formal global optimality
  proof, and upstream baseline upgrade deferred.
- [x] Keep `original/ruckig-main` frozen.
