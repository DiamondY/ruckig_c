# Ruckig C 0.5.0 Alpha.2 Tracking Hardening Checklist

This checklist records the `0.5.0-alpha.2` hardening checkpoint on the
`0.5.0-design - Unreleased` line. It is not a stable `v0.5.0` release
checklist, does not create a prerelease tag, and does not change the public C
ABI added by the first tracking alpha.

## Scope

- [x] `0.5.0-alpha.2` is a hardening/evidence checkpoint, not a feature
  expansion.
- [x] No public C API is added, removed, renamed, or signature-changed.
- [x] `include/ruckig_c/ruckig.h` has no alpha.2 diff.
- [x] `docs/abi/public-symbols.txt` remains at 164 public symbols.
- [x] `docs/abi/public-symbol-exceptions.txt` is unchanged.
- [x] `RUCKIG_TRACKING_OPTIMIZED` continues to return
  `RUCKIG_ERROR_UNSUPPORTED`; it is not aliased to Fast.
- [x] Stable `v0.5.0` may be Fast-only if the final release evidence stays
  clean.
- [x] `Optimized` tracking implementation is deferred to `0.6.0-design`.
- [x] No Pro/cloud sample, network dependency, or external license is used as
  evidence.
- [x] No `v0.5.0-alpha.2` tag or GitHub prerelease is created.
- [x] `original/ruckig-main` remains unchanged.

## C Test Hardening

- [x] Added a shared C test failure counter so failures in non-main test
  translation units now make `ruckig_c_tests.exe` exit nonzero.
- [x] Added `ruckig_c_tracking_fixed_corpus` CTest gate.
- [x] Added deterministic tracking fixed corpus coverage for ramp,
  constant-acceleration, and sinus signals over multiple Fast configurations.
- [x] Added deterministic repeat checks for 1D, 2D, and 4D tracking loops.
- [x] Added disabled-DoF tracking coverage.
- [x] Added offline tracking invariants for output count, time monotonicity,
  result codes, finite output arrays, sections, and partial failure count.
- [x] Added multi-DoF no-allocation coverage for online and offline tracking.
- [x] Quality hard gate is limited to selected tuned Fast configurations:
  ramp uses `reactiveness = 1.0`, `look_ahead_cycles = 20`; constant
  acceleration uses `reactiveness = 1.0`, `look_ahead_cycles = 2`.
- [x] Sinus tracking quality remains trend-only and is not a hard gate.
- [x] Two stale waypoint duration locks became active after the shared failure
  counter fix. They were updated to current deterministic solver outputs after
  the existing waypoint and per-section invariants passed:
  `3.210714722108343` and `2.617255105467443`.

## Python and Rust Hardening

- [x] Python `TrackingOutputSequence` now exposes acceleration, jerk, and
  section readback.
- [x] Python prototype smoke covers 1D and 2D online Fast tracking, 1D and 2D
  offline sequence tracking, invalid tracking parameters, `Optimized`
  unsupported online/offline behavior, and lifecycle checks.
- [x] Rust alpha wrapper now exposes tracking output sequence velocity,
  acceleration, jerk, and section readback.
- [x] Rust alpha tests cover 1D and 2D online Fast tracking, 1D and 2D offline
  sequence tracking, invalid tracking parameters, and `Optimized` unsupported
  online/offline behavior.
- [x] Python remains prototype-only; no wheel is published.
- [x] Rust remains alpha-only; no crate is published.
