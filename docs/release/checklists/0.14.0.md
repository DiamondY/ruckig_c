# Ruckig C 0.14.0 Release Checklist

This checklist records the stable `v0.14.0` API-neutral interrupt surface
release closeout. The release keeps the `v0.13.0` 172-symbol public C ABI
unchanged while stabilizing the `0.14.0-alpha.1` through `0.14.0-alpha.5`
interrupt evidence reviewed during `0.14.0-readiness`.

- [x] Version is `0.14.0` in `CMakeLists.txt`.

- [x] ABI artifact paths use `artifacts/abi/0.14.0`.
- [x] CI exported-symbol artifact paths use `artifacts/abi/0.14.0`.
- [x] `CHANGELOG.md` has a dated `0.14.0` release entry.

- [x] Public symbol count remains `172`.
- [x] Public additions in `v0.14.0`: `0`.
- [x] Public removals in `v0.14.0`: `0`.
- [x] Waypoint `ruckig_update` true-resume remains scoped to intermediate
  waypoint calculations.
- [x] No-waypoint `ruckig_update` supports complete-trajectory-boundary
  interruption without true-resume.
- [x] Optimized online tracking update and lookahead update support
  best-so-far complete-candidate-boundary interruption.
