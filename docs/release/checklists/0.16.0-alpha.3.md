# 0.16.0-alpha.3 Core Public Diagnostics API Checklist

Status: local evidence complete; ordinary remote push CI is observed after the
checklist commit is pushed.

This slice is the first approved public ABI expansion on the `0.16.0` public
diagnostics design line. It implements the generic diagnostics record and the
core validate/calculate/update diagnostics entry points without changing
existing result-code numeric values, existing public struct layouts, version
metadata, release/tag state, workflow, wrapper publication status, upstream
baseline, or visualization assets.

## Scope

- [x] Added public diagnostics enums and record type:
  `ruckig_diagnostic_scope_t`, `ruckig_diagnostic_code_t`, and
  `ruckig_diagnostics_t`.
- [x] Added `ruckig_diagnostics_init`.
- [x] Added `ruckig_validate_input_with_diagnostics`.
- [x] Added `ruckig_calculate_with_diagnostics`.
- [x] Added `ruckig_update_with_diagnostics`.
- [x] Kept `ruckig_validate_input`, `ruckig_calculate`, and `ruckig_update`
  behavior-compatible by routing through the same private implementation with
  `NULL` diagnostics.
- [x] Added private diagnostics helpers for init/clear, `struct_size`
  validation, bounded writes, and coarse result-code mapping.
- [x] Added `ruckig_c_public_diagnostics` focused CTest selector.
- [x] Extended C and C++ header compile smoke tests for the new public
  diagnostics symbols and types.

## Public API / ABI Delta

- [x] Baseline: `v0.15.0` public C ABI, 184 symbols.
- [x] Added 4 public symbols in this slice:
  `ruckig_diagnostics_init`,
  `ruckig_validate_input_with_diagnostics`,
  `ruckig_calculate_with_diagnostics`, and
  `ruckig_update_with_diagnostics`.
- [x] Expected symbol count after alpha.3: 188.
- [x] `docs/abi/public-symbols.txt` is updated in the same commit as the
  public header change.
- [x] No existing public symbol is removed or renamed.
- [x] Existing `ruckig_result_t` numeric values are unchanged.
- [x] Existing public struct layouts are unchanged.

## Diagnostics Contract

- [x] `ruckig_diagnostics_init(NULL)` is a no-op.
- [x] `_with_diagnostics(..., NULL)` is behavior-compatible with the legacy
  API.
- [x] Non-NULL diagnostics records with too-small `struct_size` return
  `RUCKIG_ERROR_INVALID_INPUT` before the main operation runs.
- [x] Successful operations report the operation result with
  `RUCKIG_DIAGNOSTIC_NONE`.
- [x] Invalid handles and DoF/capacity mismatches report stable coarse public
  codes.
- [x] Validation diagnostics cover non-finite values, negative limits,
  current-state out-of-limits, target-state out-of-limits, unsupported public
  combinations, and invalid enum values.
- [x] Calculation/update diagnostics map existing zero-limit, synchronization,
  trajectory-duration, and unsupported result classes without exposing solver
  branch or candidate internals.

## Deferred

- [ ] Wrapper stabilization, package-manager recipes, version bump, release
