# Ruckig C 0.7.0 Alpha.3 Coverage Audit Checklist

This checklist records the `0.7.0-alpha.3` test coverage audit evidence on the
`0.7.0-design - Unreleased` line. It is not a stable `v0.7.0` release
checklist, does not create a tag, and does not create a GitHub Release.

## Scope

- [x] `CHANGELOG.md` records `0.7.0-alpha.3` coverage audit evidence.

- [x] `docs/current/test_coverage_audit.md` records code coverage, behavior

- [x] `original/ruckig-main` remains frozen.

## Coverage Tooling

- [x] `RUCKIG_C_ENABLE_COVERAGE` is an opt-in CMake option and requires Clang.
- [x] `windows-clang-ninja-coverage` builds C tests, C examples, and oracle
  tests with LLVM coverage instrumentation.
- [x] `tools/coverage/run_coverage.ps1` configures the coverage preset, builds
  it, runs the broad routine corpus, merges `.profraw` files with
  `llvm-profdata`, and writes `llvm-cov` text and HTML reports.
- [x] Raw coverage artifacts are written under
  `out/coverage/0.7.0-alpha.3/` and remain untracked.
- [x] Coverage evidence is local-only and not added to GitHub Actions CI.
- [x] Coverage numbers are recorded as evidence and are not a hard gate.
