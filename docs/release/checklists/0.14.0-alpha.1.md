# Ruckig C 0.14.0-alpha.1 Interrupt Boundary Checklist

This checklist records the local `0.14.0-alpha.1` evidence slice on the
`0.14.0-design - Unreleased` line. It is an API-neutral interrupt boundary
audit, not `v0.14.0` readiness or stable release closeout.

## Scope

- [x] Current stable release remains `v0.13.0`.
- [x] `0.13.1` remains reserved for emergency `v0.13.0` patch fixes only.
- [x] Current `main` remains `0.14.0-design - Unreleased`.
- [x] The slice is limited to testing and documenting the existing
  `interrupt_calculation_duration` boundary.
- [x] Waypoint `ruckig_update` with intermediate waypoints remains the only
  public path that can trigger soft interruption and private true-resume.
- [x] Public `ruckig_calculate`, no-waypoint `ruckig_update`, and tracking
  remain outside waypoint interruption/resume behavior.
- [x] No public C ABI, public header signature, public struct layout, enum
  numeric value, result-code numeric value, or exported symbol is added.
- [x] No no-waypoint interruption, tracking interruption, public resume
  diagnostics API, runtime clock public hook, package-manager work,
  Cloud/remote runtime, Pro/cloud equivalence claim, hard real-time claim,
  formal global optimality proof, or upstream baseline upgrade is added.
- [x] No version bump, tag, GitHub Release, remote push CI wait, or manual
  release-random workflow is part of this alpha evidence slice.

## Added Local Coverage

- [x] Added `--interrupt-boundary-audit` to `ruckig_c_tests`.
- [x] Added CTest entry `ruckig_c_interrupt_boundary_audit`.
- [x] Covered the positive waypoint case: waypoint `ruckig_update` with an
  intermediate waypoint and zero interrupt budget publishes an initial complete
  candidate, marks the calculation interrupted, and leaves private resume
  active.
- [x] Covered no-waypoint update isolation with interrupt set, changed, and
  cleared after an active waypoint resume. The no-waypoint path reports
  `was_calculation_interrupted=false` and clears private waypoint resume state.
- [x] Covered public waypoint `ruckig_calculate` isolation: it runs a full
  waypoint solve even when the interrupt field is set and leaves no active
  private resume state.
- [x] Covered tracking isolation for `ruckig_tracking_update`,
  `ruckig_tracking_update_with_lookahead`, and
  `ruckig_tracking_calculate_sequence` with inputs that set or clear the
  interrupt field. Tracking diagnostics remain tracking-owned, and output
  interruption state is not used as a waypoint signal.
- [x] Covered allocation-guarded boundary paths for initial interrupted
  waypoint update, background interrupted-without-publish resume, and
  transition from active waypoint resume to no-waypoint update.
