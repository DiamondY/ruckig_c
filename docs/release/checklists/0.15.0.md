# Ruckig C 0.15.0 Release Checklist

This checklist records the stable `v0.15.0` tracking sequence continuation
release closeout. The release stabilizes the `0.15.0-alpha.1` through
`0.15.0-alpha.8` interruption and continuation evidence reviewed during
`0.15.0-readiness`, and promotes the 184-symbol public C ABI accepted on the
0.15 design line.

## Scope

- [x] Version is `0.15.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.15.0`.
- [x] ABI artifact paths use `artifacts/abi/0.15.0`.
- [x] CI exported-symbol artifact paths use `artifacts/abi/0.15.0`.
- [x] `CHANGELOG.md` has a dated `0.15.0` release entry.
- [x] Existing `v0.14.0` public functions are not removed or
  signature-changed.
- [x] Existing public structs, enum numeric values, result-code numeric values,
  and public diagnostics layout are unchanged except for the accepted
  continuation API additions.
- [x] Public symbol count is `184`.
- [x] Public additions in `v0.15.0`: `12`.
- [x] Public removals in `v0.15.0`: `0`.
- [x] Tracking sequence continuation API is stable C ABI in `v0.15.0`.
- [x] `ruckig_tracking_calculate_sequence` remains a complete solve.
- [x] Interruptible sequence start/resume publishes complete sequence-step
  prefixes only.
- [x] Fast and Optimized sequence continuation behavior is included.
- [x] Continuation resume rejects a same-DoF tracking handle with a different
  `delta_time`.
- [x] `RUCKIG_RESULT_IS_OK` remains header-only and adds no exported symbol.
- [x] Python `cffi` remains prototype-only; no wheel is published.
- [x] Rust remains an alpha wrapper; no crate is published.
- [x] Package-manager recipes remain deferred.
- [x] No Pro/cloud sample, network dependency, or external license is used as a
  release gate.
- [x] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
- [x] Post-release `0.16.0-design` transition is deferred.
