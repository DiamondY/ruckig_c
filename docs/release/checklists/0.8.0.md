# Ruckig C 0.8.0 Release Checklist

This checklist records the stable `v0.8.0` visualization/gallery evidence
release closeout. The release keeps the `v0.7.0` 172-symbol public C ABI
unchanged while adopting the local Matplotlib PNG gallery and verifier evidence
reviewed during `0.8.0-readiness`.

## Scope

- [x] Version is `0.8.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.8.0`.
- [x] `CHANGELOG.md` has a dated `0.8.0` release entry.
- [x] `README.md` describes `v0.8.0` as the current stable release.
- [x] `docs/current/roadmap.md` records `v0.8.0` as the stable
  visualization/gallery evidence release.
- [x] Existing `v0.7.0` public functions are not removed or signature-changed.
- [x] Existing enum numeric values and result-code numeric values are
  unchanged.
- [x] Public symbol count remains `172`.
- [x] Public additions in `v0.8.0`: `0`.
- [x] Public removals in `v0.8.0`: `0`.
- [x] The existing 13 PNG gallery assets and `manifest.json` are kept
  unchanged during closeout.
- [x] Visualization verification remains local-only; no default CI plotting or
  verifier job is added.
- [x] Python `cffi` remains prototype-only; no wheel is published.
- [x] Rust remains an alpha wrapper; no crate is published.
- [x] Package-manager recipes remain deferred.
- [x] No Pro/cloud sample, network dependency, or external license is used as a
  release gate.
- [x] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.
