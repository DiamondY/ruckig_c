# Ruckig C 0.8.0 Release Checklist

This checklist records the stable `v0.8.0` visualization/gallery evidence
release closeout. The release keeps the `v0.7.0` 172-symbol public C ABI
unchanged while adopting the local Matplotlib PNG gallery and verifier evidence
reviewed during `0.8.0-readiness`.

- [x] `CHANGELOG.md` has a dated `0.8.0` release entry.

  unchanged.

- [x] Public removals in `v0.8.0`: `0`.
