# Ruckig C 0.13.0 Release Checklist

This checklist records the stable `v0.13.0` waypoint true-resume stress and
private engine rewrite release closeout. The release keeps the `v0.12.0`
172-symbol public C ABI unchanged while stabilizing the `0.13.0-alpha.1`
stress evidence and `0.13.0-alpha.2` private engine rewrite reviewed during
`0.13.0-readiness`.

## Waypoint True-Resume Evidence

- [x] `v0.13.0` stabilizes post-`v0.12.0` waypoint `ruckig_update`
  true-resume stress evidence.
- [x] Multi-DoF, multi-waypoint, per-section, budget-matrix, fresh-solve
  reference, long online-loop, and allocation-guard coverage is included from
  `0.13.0-alpha.1`.
- [x] The private waypoint optimizer/resume state is consolidated into an
  internal waypoint engine from `0.13.0-alpha.2`.
- [x] Background resume writes to a private scratch trajectory and only copies
  a complete valid improvement into the output trajectory.
- [x] A 128-case deterministic quality baseline proves complete waypoint solve
  durations are not regressed against the `9d322ad` behavior within tolerance.
- [x] Public `ruckig_calculate` remains complete and non-interruptible.
- [x] No-waypoint `ruckig_update` and tracking do not use waypoint
  soft-interruption resume.
- [x] Soft interruption does not depend on
  `RUCKIG_C_ENABLE_CALCULATION_DURATION`.
- [x] No hard real-time guarantee, runtime clock setter, cloud fallback, or
  proprietary Pro equivalence claim is made.
