# 0.15.0-alpha.6 Optimized Tracking Sequence Continuation

Status: local alpha implementation complete.

This slice implements Optimized-mode behavior for the alpha.4 tracking sequence
continuation API. It keeps the legacy `ruckig_tracking_calculate_sequence`
entry point complete-only and uses the new continuation handle only through
`ruckig_tracking_calculate_sequence_interruptible` and
`ruckig_tracking_resume_sequence`.

## Scope

- [x] Implements Optimized `ruckig_tracking_calculate_sequence_interruptible`.
- [x] Implements Optimized `ruckig_tracking_resume_sequence`.
- [x] Stores private candidate-boundary continuation state in the opaque
  handle, including current step phase/index, best-so-far candidate target,
  input snapshot, and diagnostics.
- [x] Publishes only complete sequence-step prefixes while the current step is
  still interrupted.
- [x] Verifies completed interruptible/resume output matches the old complete
  sequence solve within deterministic tolerance.
- [x] Leaves Python/Rust wrapper smoke coverage to `0.15.0-alpha.7`.

## Public API / ABI Boundary

- [x] No public header signature changes beyond the alpha.4 API already
