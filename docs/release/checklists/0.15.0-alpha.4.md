# 0.15.0-alpha.4 Tracking Sequence Continuation API Scaffold

Status: local alpha scaffold complete.

This slice starts the explicit `0.15.0-design` public C ABI expansion for
tracking sequence interruption continuation. It adds the public continuation
handle and compact status API, but does not implement Fast or Optimized
sequence interruption behavior yet.

## Scope

- [x] Adds opaque `ruckig_tracking_sequence_continuation_t`.
- [x] Adds lifecycle and compact status accessors for continuation handles.
- [x] Adds interruptible start and resume entry point declarations.
- [x] Keeps `ruckig_tracking_calculate_sequence` complete-solve semantics.
- [x] Keeps `ruckig_tracking_diagnostics_t` layout unchanged.
- [x] Keeps result-code and enum numeric values unchanged.
- [x] Records the public symbol baseline expansion from 172 to 184 symbols.

## Behavior Boundary

- [x] Continuation lifecycle/accessors are implemented.
- [x] `ruckig_tracking_calculate_sequence_interruptible` validates and captures
  the start boundary, then returns `RUCKIG_ERROR_UNSUPPORTED` until alpha.5.
- [x] `ruckig_tracking_resume_sequence` returns `RUCKIG_ERROR_UNSUPPORTED`
  until alpha.5/alpha.6 behavior implementation.
- [x] Fast sequence continuation is deferred to `0.15.0-alpha.5`.
- [x] Optimized solver-internal sequence continuation is deferred to
  `0.15.0-alpha.6`.
- [x] Python/Rust wrapper coverage is deferred to `0.15.0-alpha.7`.
