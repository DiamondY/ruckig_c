# 0.16.0-alpha.2 Public Diagnostics Contract Freeze Checklist

Status: local evidence complete; ordinary remote push CI is observed after the
checklist commit is pushed.

This checklist freezes the public diagnostics contract for staged `0.16.0`
implementation. It is docs-only: no public header, ABI allowlist, source,
workflow, version metadata, release/tag state, wrapper publication status,
upstream baseline, or visualization asset is changed.

## Scope

- [x] Updated `docs/design/0.16.0_public_diagnostics.md` from candidate design
  to frozen staged contract.
- [x] Froze the public diagnostics type direction:
  `ruckig_diagnostic_scope_t`, `ruckig_diagnostic_code_t`, and
  `ruckig_diagnostics_t`.
- [x] Froze the staged public function direction:
  `ruckig_diagnostics_init`, `ruckig_validate_input_with_diagnostics`,
  `ruckig_calculate_with_diagnostics`, `ruckig_update_with_diagnostics`,
  `ruckig_tracking_get_last_public_diagnostics`, and
  `ruckig_tracking_sequence_continuation_get_last_diagnostics`.
- [x] Froze the non-NULL diagnostics initialization requirement:
  callers initialize with `ruckig_diagnostics_init`, while `NULL` diagnostics
  stays equivalent to the legacy API.
- [x] Froze `struct_size` compatibility rules for rejecting too-small records
  and writing only fields within the caller-provided size.
- [x] Froze stable coarse diagnostic scope/code boundaries and explicitly kept
  solver profile branches, candidate ordering, waypoint queue internals,
  solver tie-break details, and random seed/sample metadata private.
- [x] Recorded alpha.3, alpha.4, and alpha.5 implementation boundaries.

## Public API / ABI Boundary

- [x] No exported C function is added in this slice.
- [x] No public function signature is changed in this slice.
- [x] No enum numeric value or result-code numeric value is changed in this
  slice.
- [x] No public struct layout is changed in this slice.
- [x] `include/ruckig_c/ruckig.h` is unchanged.
- [x] `docs/abi/public-symbols.txt` is unchanged.
- [x] No ABI exception file, workflow, version metadata, release/tag state,
  wrapper publication status, upstream baseline, or visualization asset is
  changed.

## Future Implementation Requirements

- [ ] `0.16.0-alpha.3` must update the public header and ABI allowlist in the
  same reviewed commit when adding the core diagnostics API.
- [ ] Core `_with_diagnostics` functions must preserve legacy behavior when
  diagnostics is `NULL`.
- [ ] Non-NULL diagnostics records must be initialized with
  `ruckig_diagnostics_init`.
- [ ] Public diagnostics tests must cover initialization, too-small
  `struct_size`, `NULL` diagnostics parity, invalid input, zero limit, current
  and target limit failures, and `calculate`/`update` result parity.
- [ ] Tracking diagnostics getters remain deferred to alpha.5.
- [ ] Wrapper stabilization, package-manager recipes, release/tag actions, and
  generated fixture writes remain outside this contract freeze.
