# 0.15.0-alpha.8 Tracking Sequence Continuation Hardening

Status: local hardening gates passed; remote push CI pending.

This slice hardens the `0.15.0-alpha.4` through `0.15.0-alpha.7`
interruptible tracking sequence continuation API without expanding the public
C ABI beyond the 184-symbol alpha.4 baseline.

## Scope

- [x] Stores the initiating tracking handle's `delta_time` in the opaque
  continuation handle.
- [x] Rejects `ruckig_tracking_resume_sequence` calls when the resume tracking
  handle has the same DoF count but a different `delta_time`.
- [x] Preserves continuation state after rejected wrong-`delta_time` resume
  attempts and allows resume on another tracking handle with matching DoF count
  and `delta_time`.
- [x] Uses the captured continuation `delta_time` for output sequence
  timestamps so resume cannot silently shift the output time axis.
- [x] Unifies complete Optimized tracking and Optimized sequence continuation
  candidate enumeration through a shared internal candidate-step engine.
- [x] Expands Fast and Optimized continuation tests across `delta_time`,
  strategy, DoF, disabled-DoF, interrupt-budget, candidate-limit, invalid-input,
  diagnostics, and allocation-guard boundaries.
- [x] Adds the header-only `RUCKIG_RESULT_IS_OK` helper macro and documents
  diagnostics reserved fields plus C++ opaque typedef usage.

## Public API / ABI Boundary

- [x] No exported C symbols are added beyond the 184-symbol alpha.4 baseline.
- [x] No public function signature changes are introduced.
- [x] No enum numeric values or result-code numeric values change.
- [x] No public diagnostics struct fields or public struct layouts change.
- [x] No version metadata, tag, GitHub Release, package-manager recipe,
  wrapper publication, push, or manual workflow is introduced by this local
  slice.
- [x] `RUCKIG_RESULT_IS_OK` is a header-only macro and does not add a dynamic
  library symbol.
