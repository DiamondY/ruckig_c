# Ruckig C 0.12.0 Release Checklist

This checklist records the stable `v0.12.0` waypoint soft-interruption
true-resume release closeout. The release keeps the `v0.11.0` 172-symbol
public C ABI unchanged while stabilizing the `0.12.0-alpha.1` true-resume and
`0.12.0-alpha.2` unified-engine hardening slices reviewed during
`0.12.0-readiness`.

## Soft Interruption True-Resume Evidence

- [x] `v0.12.0` stabilizes `0.12.0-design` waypoint `ruckig_update`
  soft-interruption true-resume.
- [x] Initial waypoint soft-interruption can publish the best complete
  feasible candidate found before budget expiry and keep private resume state
  active.
- [x] Later normal `pass_to_input` online cycles can continue the optimizer in
  the background while the interrupt field remains enabled.
- [x] Background publish only replaces the old trajectory with a complete
  feasible candidate that improves over incumbent remaining duration.
- [x] Background budget expiry without a publishable candidate keeps sampling
  the old trajectory and returns `RUCKIG_WORKING`.
- [x] Complete waypoint solves and soft-interruption resume share the same
  private step-driven optimizer engine.
- [x] Public `ruckig_calculate` remains complete and non-interruptible.
- [x] No-waypoint `ruckig_update` and tracking do not use waypoint
  soft-interruption resume.
- [x] Soft interruption does not depend on
  `RUCKIG_C_ENABLE_CALCULATION_DURATION`.
- [x] No hard real-time guarantee, runtime clock setter, cloud fallback, or
  proprietary Pro equivalence claim is made.
