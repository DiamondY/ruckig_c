# 0.15.0-alpha.1 Interrupt Post-Release Quality Baseline

Status: local gates passed; committed as local alpha evidence.

This slice starts the `0.15.0-design - Unreleased` line after the published
`v0.14.0` stable release. It adds a focused post-release quality selector for
the interrupt surfaces stabilized in `v0.14.0` without changing public C API,
public ABI, version metadata, tags, GitHub Releases, remote CI state, or
manual workflows.

## Scope

- [x] Added `--interrupt-post-release-quality` to `ruckig_c_tests`.
- [x] Added CTest `ruckig_c_interrupt_post_release_quality`.
- [x] Reuses the 128-case waypoint true-resume quality audit as the waypoint
  post-release baseline.
- [x] Adds a deterministic no-waypoint quality corpus that compares first-solve
  and later full-budget publishes against complete `ruckig_calculate`
  references while checking zero-budget incumbent preservation.
- [x] Reuses Optimized online tracking update/lookahead interruption checks for
  best-so-far complete-candidate publish and diagnostics consistency.
- [x] Keeps public `ruckig_calculate` as a complete solve that ignores the
  interrupt budget.
- [x] Keeps `ruckig_tracking_calculate_sequence` deferred; no API-neutral
  sequence interruption carrier is added.

## Boundaries

- [x] No change to `include/ruckig_c/ruckig.h`.
- [x] No new public function, public struct, exported symbol, enum value,
  result-code value, public diagnostics field, or runtime clock public hook.
- [x] No version bump, `v0.15.0*` tag, GitHub Release, push, or manual
  `release-random` workflow.
- [x] `RUCKIG_C_ENABLE_CALCULATION_DURATION` remains only the public
  `calculation_duration` reporting gate; interruption availability is exercised
  by the same selector in the normal and duration-enabled builds.
