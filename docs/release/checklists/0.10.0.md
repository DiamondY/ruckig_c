# Ruckig C 0.10.0 Release Checklist

This checklist records the stable `v0.10.0` Visualization v2 evidence release
closeout. The release keeps the `v0.9.0` 172-symbol public C ABI unchanged
while adopting the Visualization v2 gallery, local verifier, strict
regeneration, and manual-only CI artifact evidence reviewed during
`0.10.0-readiness`.
