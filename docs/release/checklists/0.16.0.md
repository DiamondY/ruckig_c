# Ruckig C 0.16.0 Release Checklist

This checklist records the stable `v0.16.0` public diagnostics release
closeout. The release stabilizes the `0.16.0-alpha.3` through
`0.16.0-alpha.5` public diagnostics API, state/resume mapping, tracking getter,
and readiness evidence reviewed during `0.16.0-readiness`, and promotes the
190-symbol public C ABI accepted on the 0.16 design line.

## Scope

- [x] Version is `0.16.0` in `CMakeLists.txt`.
- [x] Version macros in `include/ruckig_c/ruckig.h` are `0.16.0`.
- [x] ABI artifact paths use `artifacts/abi/0.16.0`.
- [x] CI exported-symbol artifact paths use `artifacts/abi/0.16.0`.
- [x] `CHANGELOG.md` has a dated `0.16.0` release entry.
- [x] `docs/release/notes/0.16.0.md` records stable release notes.
- [x] Existing `v0.15.0` public functions are not removed or
  signature-changed.
- [x] Existing public structs, enum numeric values, and result-code numeric
  values are unchanged.
- [x] Public symbol count is `190`.
- [x] Public additions in `v0.16.0`: `6`.
- [x] Public removals in `v0.16.0`: `0`.
- [x] Public diagnostics are stable, opt-in C ABI in `v0.16.0`.
- [x] Legacy validate/calculate/update behavior and result-code compatibility
  are preserved.
- [x] `_with_diagnostics(..., NULL)` remains equivalent to the matching legacy
  API.
- [x] Tracking diagnostics use getter-style accessors rather than per-operation
  `_with_diagnostics` variants.
- [x] Solver profile branches, waypoint branch queues, tracking candidate
  ordering, score internals, optimizer phases, and random seed/sample tooling
  state remain private.
- [x] Python `cffi` remains prototype-only; no wheel is published.
- [x] Rust remains a prototype wrapper; no crate is published.
- [x] Package-manager recipes remain deferred.
- [x] No Pro/cloud sample, network dependency, or external license is used as a
  release gate.
- [x] `original/ruckig-main` remains frozen as Ruckig Community `0.17.3`.

  work.
- [x] `0.16.0-alpha.3` adds the core validate/calculate/update diagnostics
  public API and focused selector `ruckig_c_public_diagnostics`.
- [x] `0.16.0-alpha.4` extends interruption and waypoint resume diagnostics

  190-symbol public diagnostics design line.
- [x] No runtime clock setter, hard real-time claim, cloud fallback,
  proprietary Pro equivalence claim, Python wheel, Rust crate, or
  package-manager recipe is added.
