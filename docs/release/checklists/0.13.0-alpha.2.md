## Added Local Coverage

- [x] Rewrote the private waypoint optimizer/resume storage into a single
  internal `waypoint_engine` state under `ruckig_t`.
- [x] Kept waypoint complete solve, initial interrupted solve, and background
  resume on the same private candidate engine.
- [x] Added a transaction-style publish boundary: the engine writes a scratch
  trajectory first and only copies a complete valid improvement into the output
  trajectory.
- [x] Added `--waypoint-resume-quality-audit` to `ruckig_c_tests`.
- [x] Added CTest entry `ruckig_c_waypoint_resume_quality_audit`.
- [x] Captured a checked-in 128-case deterministic complete-solve duration
  baseline from current engine commit `9d322ad`.
- [x] The quality audit asserts each successful complete waypoint solve is not
  slower than the baseline duration plus `1e-9`.
- [x] The quality audit records background publish,
  interrupted-without-publish, resume completion, and fresh full-solve
  reference counts across corpus online loops.
