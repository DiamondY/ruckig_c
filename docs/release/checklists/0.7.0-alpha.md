# Ruckig C 0.7.0 Alpha Optimized Tracking Strategy Checklist

This checklist records the `0.7.0-alpha` Optimized tracking strategy evidence
on the `0.7.0-design - Unreleased` line. It is not a stable `v0.7.0` release
checklist, does not create a tag, and does not create a GitHub Release.

## Scope

- [x] `CHANGELOG.md` records `0.7.0-design - Unreleased` Optimized tracking
  strategy alpha scope.
- [x] `docs/design/tracking_optimized_mode.md` records the accepted strategy
  API, preset semantics, bounded evaluator behavior, fallback policy,
  no-allocation policy, and evidence strategy.
- [x] `README.md`, `docs/current/roadmap.md`, and
  `docs/current/original_parity_coverage.md` distinguish stable `v0.6.0`
  Optimized tracking from `main`'s `0.7.0-alpha` strategy evidence.
- [x] No stable tag, prerelease tag, or GitHub Release is created from this
  alpha evidence.
- [x] No cloud, remote calculation, Pro sample, network dependency, or
  external license is used as a gate.
- [x] Soft interruption checkpoints, formal Python/Rust publication,
  package-manager recipes, cloud/remote calculation, Pro/cloud equivalence
  claims, and upstream baseline upgrade remain deferred.
- [x] `original/ruckig-main` remains frozen.

## Public C ABI Review

- [x] Existing `v0.6.0` public functions and signatures are not removed or
  modified.
- [x] Existing enum numeric values and result-code numeric values are
  unchanged.
- [x] New public symbols are limited to the approved Optimized tracking
  strategy API:
  `ruckig_tracking_set_optimized_strategy` and
  `ruckig_tracking_get_optimized_strategy`.
- [x] `ruckig_tracking_optimized_strategy_t` adds
  `RUCKIG_TRACKING_OPTIMIZED_STABLE = 0`,
  `RUCKIG_TRACKING_OPTIMIZED_BALANCED = 1`, and
  `RUCKIG_TRACKING_OPTIMIZED_AGGRESSIVE = 2`.
- [x] Default strategy after `ruckig_tracking_create` is
  `RUCKIG_TRACKING_OPTIMIZED_BALANCED`.
- [x] Invalid strategy values return `RUCKIG_ERROR_INVALID_INPUT`.
- [x] Default candidate budget remains `16`; valid range remains `1..128`.
- [x] `docs/abi/public-symbols.txt` contains 171 approved public symbols.
- [x] `docs/abi/public-symbol-exceptions.txt` records the approved
  `0.7.0-alpha` additions.
- [x] ABI artifact paths use `artifacts/abi/0.7.0-alpha`.
- [x] Public symbol allowlist verification passes.
- [x] Public exported-symbol comparison passes.
- [x] Public header diff against `v0.6.0` is reviewed and limited to approved
  strategy API additions and comments.

## Optimized Tracking Strategy Evidence

- [x] C implementation supports `Stable`, `Balanced`, and `Aggressive`
  strategy presets.
- [x] Candidate generation, scoring, best-candidate storage, and final update
  execution are factored into deterministic internal helpers.
- [x] Candidate families remain bounded and deterministic: Fast baseline,
  instantaneous samples, horizon-predicted samples, terminal blends,
  derivative-damped terminal candidates, and strategy-specific lead/lag
  variants.
- [x] Fast fallback returns normal control-flow results and is observable
  through `ruckig_tracking_get_last_calculation_status`.
- [x] Offline diagnostic status aggregates all steps; `last_candidate_count`
  records total evaluated candidates.
- [x] Invalid inputs and infeasible baseline errors use existing result codes;
  no public result enum is added.
- [x] Prepared Optimized online/offline paths are covered by no-allocation
  tests for all strategies.
- [x] Balanced weighted tracking error is not worse than Fast baseline on fixed
  ramp, constant-acceleration, sinus, and half-sinus cases within tolerance.
- [x] Aggressive weighted tracking error improves over Balanced by at least
  `1%` on fixed sinus and half-sinus cases.
- [x] Tracking random stress covers DoF 1/2/4/8, signal variants, lookahead
  variants, reactiveness variants, strategies, disabled DoFs, and tight valid
  constraints.
- [x] C examples cover Optimized strategy usage.
