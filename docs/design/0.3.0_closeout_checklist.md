# 0.3.0-design Closeout Checklist

This checklist defines the engineering-hardening closeout criteria for the
`0.3.0-design` line. It is not a release checklist and does not approve public
C API additions, solver changes, bindings release work, package-manager
recipes, or upstream baseline upgrades.

## Required Evidence

- Local Windows default preset:
  - `cmake --preset windows-clang-ninja`
  - `cmake --build --preset windows-clang-ninja`
  - `ctest --preset windows-clang-ninja`
- Local Windows shared/ABI preset:
  - `cmake --preset windows-clang-ninja-shared`
  - `cmake --build --preset windows-clang-ninja-shared`
  - `ctest --preset windows-clang-ninja-shared`
  - `cmake --build out/build/windows-clang-ninja-shared --target ruckig_c_verify_public_symbols`
  - `cmake --build out/build/windows-clang-ninja-shared --target ruckig_c_compare_public_exported_symbols`
- Remote GitHub Actions evidence for the current closeout commit:
  - routine Windows, Linux, and macOS build-test jobs,
  - Linux sanitizer and Valgrind jobs,
  - Linux performance artifact,
  - Windows MinGW static and DLL consumer jobs,
  - Linux and Windows exported-symbol artifacts.
- macOS shared/export evidence bootstrap:
  - shared build passes on `macos-latest`,
  - `ruckig_c_verify_public_symbols` passes,
  - Mach-O exported-symbol snapshot is uploaded as an artifact.

## Consumer Matrix

- Installed CMake package remains verified.
- Unix pkg-config remains verified where `pkg-config` is available.
- Windows clang static and DLL consumers remain verified.
- Windows clang-cl static and DLL consumers remain routine CI paths.
- Windows MinGW static and DLL consumers remain routine CI paths.
- MSVC `cl` static and DLL consumers remain opt-in local gates, not routine CI.
- macOS shared/export evidence is bootstrap evidence only until a historical
  macOS ABI baseline policy is accepted.

## Python Prototype

- The prototype remains under `bindings/python_prototype/`.
- It must load a prebuilt shared library through `RUCKIG_C_SHARED_LIBRARY` for
  documented smoke tests.
- It must cover lifecycle, copy-in/copy-out arrays, normal result codes, typed
  error-code exceptions, offline calculation, and online update loops.
- It is not installed by CMake, not published, and not part of routine CI.

## Scope Freeze

- `include/ruckig_c/ruckig.h` must not gain new public C API for this closeout.
- `docs/abi/public-symbols.txt` must not change without a separate public API
  design and version decision.
- `docs/abi/public-symbol-exceptions.txt` stays empty unless a separately
  approved public API addition exists.
- Package-manager recipes and new package-manager prototypes remain long-term
  optional and frozen.
- Waypoints, per-section constraints, and cloud calculation remain independent
  design projects.
- Rust bindings remain deferred until Python feasibility has clearer ownership,
  error, array, and packaging conclusions.
- Upstream Ruckig baseline upgrades remain a separate project.

## Cleanup

- Run `./scripts/clean-local.ps1` as a dry run.
- Run `./scripts/clean-local.ps1 -Apply` only after the preview contains only
  ignored local artifacts.
- Local build trees should stay under `out/build/` through checked-in presets.
- Root `build*` directories should not accumulate during routine development.
